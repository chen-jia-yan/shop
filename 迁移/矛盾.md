```python
        temperature: float | None = None,
        max_tokens: int | None = None,
        extra_headers: dict[str, str] | None = None,

    ) -> StreamingCompletion[TextDelta]: ...

    def astream_turn(

```

三問回答:
1. acompletion 是否支持非流式? 不支持。返回類型是 StreamingCompletion[TextDelta], 只支持流式輸出。沒有非流式返回完整文本的接口。
2. 能否要求模型返回 JSON 格式? 接口層面沒有 response_format 或 json_mode 參數。可按 messages 內容引導模型輸出 JSON, 但接口不保證。
3. Langfuse 在哪一層自動紀錄? 在 plugins/observability/langfuse.py 層, 透過 ObservabilityScope 傳入 astream_turn 。core 層不 import Langfuse。

```python
def _probe_skill_index(react_deps):
    async def _probe() -> bool:
        if react_deps is None or react_deps.skill_catalog is None:
            return False  # ← 未配置時直接返回 False，但這不影響整體就緒

        except (OSError, RuntimeError, ValueError):
            return False
    return _probe
```
