# ai-dev-kit：个人 AI 开发工具包（2.1）

给 GitHub Copilot CLI 用的一整套“规则 + 能力 + 防线”。离线可用，只依赖 Python 标准库。

## 它解决什么问题
| 你遇到的问题 | 工具包里的对应能力 |
|---|---|
| 规则太死，什么事都走一遍开发流程 | **三种模式**：随手问（直接答）/ 工作台（当前目录放手做）/ 项目开发（完整流程）。自动判断，机器人右键可以手动切换 |
| 每次都要自己选技能、选代理 | **能力目录 + 自动匹配**：每个技能和代理都写了“用户会这样说”，按你的原话本地匹配；只读的直接用，会改文件的先问你 |
| 数据被测试或脚本删掉 | **删数据当场确认**：守卫在 Copilot 里弹确认框并附风险评估（删什么、多大范围、能否恢复、删前建议），你选“同意”就接着做，任务不中断；删缓存、构建目录这类中间产物直接放行；测试和脚本自动套上禁删保护 |
| 明明一步能做完，却一个包一个配置地碎步做 | **一次做完**：缺包缺配置用 kit_env.py 一次查全；同一个文件反复改、同一个命令反复跑、分次装包或改配置时，钩子会提醒它停下来列全再做 |
| 同事一起开发的模块（问答插件）怕改坏 | **共享模块护栏**：可以改、可以优化，但要先记录测试基线、保持接口兼容、改完对比基线 |
| 说了“不要做”它还是做（读 .env、git add .、装包） | **钩子硬拦截**（guard.py）：红线直接拒绝（AI 跳过那一步继续别的）/ 黄线当场问你 / 中间产物放行，同一类问题只问一次 |
| 测试“通过”是假的（0 条、收集中断、全跳过、永真断言） | 一键验证 run_checks.py + 静态检查 checks.py |
| 想把自己写的技能给别人用 | **技能试用台**：校验 → 挂到本机试用 → 试自动匹配 → 打包发给别人 |
| 做过的好方法下次又忘了 | **方法沉淀**：任务结束时起草最多 1 条方法，你同意后收进方法库，下次自动匹配 |
| 想随时知道进行到哪、时间和 token 花在哪 | **桌面机器人 + 数据面板**：“该你了 / 执行中”用头顶的对话泡泡提醒；双击机器人随时打开数据面板（任务结束后也能看），按钮切换总览 / 时间 / 能力 / 工具 / Token / 最近几轮；背景透明、可拖动调大小 |
| 写出来的代码不像项目自己的风格 | 风格包 style-tap-backend |
| 每次都要重新交代背景 | 记忆系统 mem.py（带引用、自动核对是否过期） |

## 三分钟上手
```
cd <工具包目录>
python tools/install.py          # 安装或升级（可以反复运行，旧配置自动迁移并备份）
python tools/kit_doctor.py       # 体检：每项都会告诉你怎么修
python tools/selftest.py         # 自测：只在临时目录里跑，不写任何示例数据
python tools/run_evals.py        # 评估：58 条用例
widget\start_widget.bat          # 打开桌面机器人和数据面板
```
安装后打开 Copilot，**直接用大白话说需求**就行。详见 docs/02 和 docs/11（2.1 的守卫和机器人变化在 11 的最前面）。

## 目录
```
agents/        8 个自定义代理（总调度、规划、执行、评审、验证、排障、提示词教练、技能工匠）
skills/        18 个技能（kit- 开头，kit-autopilot 是开发总流程）
style-packs/   风格包（style-tap-backend + 新建模板）
hooks/         钩子：session_start（注入）、guard（拦截）、post_edit（写后检查）、kit_events（计时、提醒、确认后补范围）
runtime/       禁删保护（测试和脚本运行时拦下真实删除）
tools/         命令行工具
templates/     提示词模板
memory/        记忆库
evals/cases/   评估用例
widget/        桌面机器人
instructions/  个人规则、项目 AGENTS.md 模板
docs/          使用文档（从 01 开始按顺序读；2.0 / 2.1 新功能看 11）
registry.json  机器人右键菜单定义
```
