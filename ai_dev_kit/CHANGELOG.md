# 更新记录

## 2.0.0（2026-11-21）
- 三种模式：随手问 / 工作台 / 项目开发，自动判断，机器人右键可切换；个人规则改成红线、原则、方法、记忆四层。
- 守卫三档：拒绝 / 先问你 / 放行；同一类只问一次。
- 删除数据先评估风险、等你同意：守卫拦下并给出风险评估，你回复“同意”只放行这一条；测试和脚本通过 kit_run.py 在禁删保护下运行，同意后加 --allow-delete；拒绝后不换写法重试。
- 一次做完：kit_env.py 一次查全缺的包、命令、配置；同文件反复改、同命令反复跑、分次装包或改配置时钩子提醒。
- 共享模块（原受保护区域）：可以改、可以优化，先记测试基线、保持接口兼容、改完对比；新增技能 kit-shared-change。
- 能力目录 + 本地匹配：技能和代理按你的原话自动推荐，只读的直接用，会改文件的先问。
- 技能试用台 kit_skill.py（check / add / try / pack / list / remove）和代理 kit-skill-smith；方法沉淀 /kit-retro。
- 新增技能：kit-data-safety、kit-env-fix、kit-workbench、kit-skill-lab、kit-retro、kit-shared-change；所有技能和代理补了触发说法、不适用、风险。
- 桌面机器人：删掉小猫，右侧新增数据面板（4 个频道每 6 秒轮播，轮到你时停在提醒卡片）；统计存于 ~/.ai-dev-kit/metrics，不放任何示例数据。
- 钩子拆成核心和扩展两个文件；旧配置自动迁移（先备份）；评估用例增至 53 条。

## 1.2.0（2026-11-19）
- 项目自动识别：在哪个目录打开 Copilot 就用哪个项目。登记过的用登记设置；没登记的 git 仓库按 pyproject / uv.lock / tests 自动推断测试命令；不在仓库里当作普通助手，不走开发流程。
- 所有工具的 --project 都可以省略（默认当前目录）；新增 tools/kit_project.py（查看 / 登记 / 删除项目）。
- 桌面宠物简化：不用选项目（自动跟随 Copilot），单击直接告诉你“现在该做什么”，右键只保留 5 项，其余收进“更多工具”和“设置”；第一次打开有引导；新会话开始时会打招呼并显示项目。
- registry.json 支持 "pin": true，把常用按钮放到菜单第一层。

## 1.1.0（2026-11-19）
- 新增自动流程：技能 kit-autopilot + 总调度代理 kit-orchestrator。说需求后自动分析、出方案，回复“确认”后逐步执行、验证、评审；每次修复前先问你；git 提交仍由你执行。
- 个人规则和会话开头注入都写明“开发需求默认走自动流程”，不用每次手动调用。
- 适配公司 bat 只能开一个会话：执行和评审交给子代理（独立上下文），不再需要开新窗口；不支持委派时自动退回自己执行。
- 桌面挂件改成桌面宠物：Q 版小机器人 / 小猫，表情和动作跟着进度变化；需要你处理时跳起来提醒；守卫拦截时举盾牌；右键菜单来自 registry.json。
- 新增进度工具 kit_status.py；新增评估用例 a01（总调度必须等确认）；自测新增 3 项。
