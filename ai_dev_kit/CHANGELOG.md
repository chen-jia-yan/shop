## 2.1.0（2026-11-23）
- 守卫少打断、改成当场确认：
  - 删数据、删源码目录、改方案外的文件：守卫在 Copilot 里直接弹确认框（附风险评估），你选“同意”就接着执行，任务不中断；不再是“拦下 → 停下来问 → 你回复同意 → 重新跑”。
  - 删缓存、构建目录、临时文件、本次会话新建的文件这类中间产物：直接放行。删 .git、整个项目目录、家目录：仍然直接拒绝。
  - 在项目里直接跑 pytest / python 脚本：守卫自动给命令套上 kit_run.py 禁删保护，不再拦下要求重写。
  - 被拒绝时，AI 跳过这一步继续做其余部分，最后在报告里写明需要你做什么，不会因此结束整个任务。
  - 引号里的 > 和 ; 不再误判成写文件、拆命令。
  - 退路：如果你的 Copilot 版本不弹确认框，把 guard.ask_mode 改成 "deny"（回到 2.0 的做法）；不支持自动改写命令时把 nodelete.auto_wrap 改成 false。
- 桌面机器人：
  - “该你了 / 执行中”改成头顶的对话泡泡（单独的小窗口），带一键复制的回复，处理完自己收起；去掉固定的任务进度框和“说需求”输入框。
  - 数据面板单独成窗：双击机器人或点右下角小图标随时打开，任务结束后也能看（修掉了一轮结束后提醒卡盖住数据、点不动的问题）；顶上按钮切换总览 / 时间 / 能力 / 工具 / Token / 最近几轮。
  - 面板默认背景透明，只显示动态进度条；可以换深色、调透明度；拖右下角或边框调大小，内容跟着放大，大小位置都记住。
  - 机器人默认小尺寸，面板默认大尺寸，面板跟着机器人移动。
- 规则、技能、代理里“停下来等同意”的说法改成“当场确认、被拒绝就跳过继续”；评估用例 58 条（新增 5 条，旧的删除流程用例保留为退路用例）。

## 1.2.0（2026-11-19）
- 项目自动识别：在哪个目录打开 Copilot 就用哪个项目。登记过的用登记设置；没登记的 git 仓库按 pyproject / uv.lock / tests 自动推断测试命令；不在仓库里当作普通助手，不走开发流程。
- 所有工具的 --project 都可以省略（默认当前目录）；新增 tools/kit_project.py（查看 / 登记 / 删除项目）。
- 桌面宠物简化：不用选项目（自动跟随 Copilot），单击直接告诉你“现在该做什么”，右键只保留 5 项，其余收进“更多工具”和“设置”；第一次打开有引导；新会话开始时会打招呼并显示项目。
- registry.json 支持 "pin": true，把常用按钮放到菜单第一层。
