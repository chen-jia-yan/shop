# 07 扩展指南（动态增量）

原则：**桌面机器人和工具代码不用改**，新增能力都通过“加文件 + 登记”完成，脚手架帮你生成正确格式，kit_lint 帮你检查。

## 新增一个技能
```
python tools\kit_new.py skill kit-api-doc "根据接口代码生成接口文档。用于新增或修改接口之后。" --button "写接口文档"
```
1. 编辑生成的 `skills/kit-api-doc/SKILL.md`：什么时候用、步骤、输出格式、不要做。
2. 细节多就放到 `skills/kit-api-doc/references/xxx.md`，正文里用 `references/xxx.md` 引用（kit_lint 会检查文件存在）。
3. `python tools\install.py` 同步到 Copilot；会话里 `/skills reload`。
4. 加了 `--button` 的话，下次右键机器人时“更多工具”里就有新按钮（每次打开菜单都重新读取 registry.json）；想放到第一层，就在 registry.json 里给它加上 `"pin": true`。

规则：名字小写加连字符、和目录同名；description 写清“做什么 + 什么时候用”；正文 ≤500 行；**不要**在 allowed-tools 里预先放行 shell。

## 新增一个自定义代理
```
python tools\kit_new.py agent kit-sql-reviewer "只读审查 SQL 和迁移脚本。" --tools read,grep,glob --button "SQL 评审" --template review
python tools\install.py
```

## 给现有项目加风格卡片
```
python tools\kit_new.py card style-tap-backend 09-redis-cache "Redis 缓存"
```
然后让 Copilot 用 `/kit-extract-pattern` 从代码里提炼内容填进去，并在风格包 SKILL.md 的表格里加一行。

## 接入一个新项目
```
python tools\kit_project.py add "C:\code\my-service"        （其实不登记也能用：在 git 仓库里会自动识别）
python tools\kit_new.py pack style-my-service "my-service 的代码风格包"
```
再打开 kit.config.json 补全测试命令、共享模块、注意事项；用 `/kit-extract-pattern` 提炼 3～8 张卡片；需要的话复制 `instructions/AGENTS.template.md` 到项目根目录。

## 新增桌面机器人按钮（不写代码）
```
python tools\kit_new.py button my-tool "我的工具" --tool "{kit}/tools/my_tool.py"
```
需要给脚本传参数（例如 `--project {project_name}`）时，生成后直接在 `registry.json` 里该按钮的 `command` 数组末尾补上。
或者完全手写 `registry.json`。按钮类型：
| kind | 必填字段 | 说明 |
|---|---|---|
| launch_agent | agent, template | 生成提示词并复制，提示你在 Copilot 里用 /agent 选择这个代理 |
| prompt_only | template 或 prompt | 只生成并复制 |
| run_tool | command | 后台运行，结果显示在输出框 |
| open_path | path | 打开文件或目录 |
| builtin | builtin（new_request / status / memory_add） | 内置功能：说需求、当前进度、记住一件事 |
可用占位符：`{python}` `{kit}` `{project}` `{project_name}` `{git_root}` `{task}` `{task_line}` `{lean_flag}` `{output_file}` `{profile}`。值为空的参数会自动去掉（连同前面的 `--选项`）。
可选字段：`requires_project`、`requires_task`、`timeout`、`description`（鼠标悬停时显示）。

## 把新事故变成用例
```
python tools\kit_new.py case inc16-xxx --type guard
python tools\run_evals.py --case inc16-xxx
```
详见技能 /kit-eval-writer。

## 新增提示词模板
在 `templates/` 下新建 `xxx.md`（第一行写 `{{rules}}` 以命中缓存），可用占位符：`{{rules}} {{task}} {{project_block}} {{project_name}} {{files}} {{verify_cmd}} {{style_hint}} {{output_block}} {{ref}} {{kit}} {{python}}`。

## 每次扩展后
```
python tools\kit_lint.py
python tools\selftest.py
python tools\run_evals.py
```
