# 评审输出格式

```
【评审范围】基准：…… 改动文件 N 个：……
【范围核对】范围外文件：无 / 有（列出）
【自动检查】（checks.py 的原始结果摘要）
【结论】可以提交 / 改完再提交 / 需要返工

【严重问题】（必须改）
1. 文件:行号 — 问题是什么 — 为什么严重 — 具体怎么改
2. ……

【一般问题】（应该改）
1. 文件:行号 — ……

【建议】（可以改）
1. ……

【声称完成 vs 实际】
| 报告里的条目 | 代码里找到了吗 | 位置 |
|---|---|---|

【给执行者的修复提示词】（把严重和一般问题整理成可以直接发给 Copilot 的 R3 格式提示词）

【核对表】
- [ ] 自己看了 diff，没有只看报告
- [ ] 跑了 checks.py
- [ ] 六份清单都过了一遍
- [ ] 每个问题都有 文件:行号 和改法
- [ ] 没有修改任何文件
```

没有问题的分类写“无”，不要省略标题——省略会让人分不清是“没问题”还是“没检查”。
