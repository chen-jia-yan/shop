# 共享模块兼容性检查清单

## 函数和类
- [ ] 已有函数的参数没有删除、没有改名、没有改顺序
- [ ] 新增参数都有默认值，不传时行为和以前一样
- [ ] 返回值的类型和结构没变（字段只增不减）
- [ ] 抛出的异常类型没变（调用方可能在 except 它）
- [ ] 公开的类、函数、常量没有删除或改名（要改名时保留旧名作为别名）

## 配置
- [ ] 配置字段名没变；新增字段有默认值
- [ ] 新功能开关默认关闭，不影响现有行为
- [ ] 环境变量名没变

## 数据和接口
- [ ] 写入的数据格式向后兼容（旧数据还能读）
- [ ] HTTP 接口的路径、方法、请求和返回字段没变
- [ ] 图数据库的标签、关系类型、属性名没变；查询仍然按 scope 等范围过滤
- [ ] 没有新增删除数据的逻辑（有的话要按 /kit-data-safety 问用户）

## 行为
- [ ] 默认路径下的行为和以前一样（只修了 bug 的地方除外，要写进变更说明）
- [ ] 性能没有明显变差（循环里没有新增查询、没有新增同步网络调用）
- [ ] 日志没有泄露密钥和用户数据

## 验证
- [ ] 基线对比：通过数没变少，失败数没变多
- [ ] 新增了覆盖本次改动的测试
- [ ] 变更说明写好了
