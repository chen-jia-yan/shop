# 评测用例：知识生成 PPT

> 示例数据均为虚构。脚本尚需在装有 python-pptx 和 openpyxl 的环境中实际运行验证。

## A. 渲染与校验

| # | 命令 / 操作 | 预期 |
|---|---|---|
| A1 | `python scripts/render_pptx.py examples/q3_review.json out/经营汇报.pptx` | 成功；信赖科技蓝；18 页（含自动插入的目录、执行摘要）；第 11 页的图表数据读自 `kb-to-excel/examples/branch_dashboard.json` |
| A2 | `python scripts/render_pptx.py examples/product_training.json out/上市培训.pptx` | 成功；橙白活力；25 页（含目录）；问答页 3 组正好一页（超过 3 组时自动拆页） |
| A3 | `python scripts/render_pptx.py examples/client_brief.json out/客户说明.pptx` | 成功；淡雅米橙；6 页；结束页前自动插入“重要提示”（保障型条目）；保障责任、雷达、案例页右下角有“示例样本” |
| A4 | A1 依次加 `--theme orange / warm / soft / minimal / premium / teal` | 7 份内容一致；除尊享深绿外，封面、章节页、结束页都是浅底，没有整页铺满主色 |
| A5 | `python scripts/render_pptx.py examples/q3_review.json out/经营汇报_精简版.pptx --brief` | 12 页：封面、目录、执行摘要、3 个章节页、4 张 key 页、总结、结束；页脚短标题带“（精简版）” |
| A6 | A1 加 `--no-animation` | 质检报告中“有动画 0 页” |
| A7 | `python scripts/review_pptx.py out/客户说明.pptx --external` | 通过：有重要提示页；无违规用语 |
| A8 | `python scripts/review_pptx.py out/上市培训.pptx --external` | 问答页“避免说”栏里的“保本”“稳赚不赔”不算违规；但问题原文“这个保险能保本吗？”会被列出——培训材料本就不对外，此项用于确认检查有效 |
| A9 | 把 client_brief.json 的 `external` 改为 false 后渲染，再跑 A7 | 不通过：对外材料缺少“重要提示”页 |

### 校验与提示（应退出码 2，或在构建报告中出现）

| # | 修改 | 预期 |
|---|---|---|
| A10 | 雷达图某个系列少写一个值 | 退出码 2：数据个数与维度个数不一致 |
| A11 | 方块地图加一项 `{"label": "海南", "value": 0.1}` 且不写 pos | 退出码 2：区域没有预设位置，提示写 pos 或补充 rules |
| A12 | 把 data_from 的 series 改成 `["达成率"]`（公式列） | 退出码 2：内容 JSON 里没有公式列的计算结果，提示改用打开保存过的 .xlsx |
| A13 | 把 data_from 的 file 改成不存在的文件 | 退出码 2：读取失败 |
| A14 | 瀑布图写 10 项 | 退出码 2：最多 9 项 |
| A15 | 把第 8 页标题改成“区域达成情况” | 构建报告：标题像话题；数据页标题里没有数字；图表标出了“华东”但标题没提到 |
| A16 | meta.duration_min 改成 8 | 构建报告：预计讲述超出会议时长，列出可删减的页，并建议 --brief |
| A17 | 某页 kpis 四张卡都写 highlight: true | 构建报告：强调 4 项，超过 2 项 |
| A18 | 某个 bullets 页放 12 条要点 | 自动拆成 2 页，第 2 页标题加“（续）” |

## B. 用 PowerPoint 打开逐项看

**经营汇报.pptx（信赖科技蓝）**

| 页 | 预期 |
|---|---|
| 1 封面 | 白底；左侧标题和信息，右侧深海蓝→科技蓝色块带网格线和白色图标；左下橙色短色带 |
| 2 目录 | 3 张章节卡片，各显示页数和“约 N 分钟”；副标题“共 3 个部分，约 N 分钟” |
| 3 执行摘要 | 标题“三季度超额完成目标，华东和价值率是两个短板”（后半句强调色）；4 条结论分别指向 P05、P08、P09、P16，第 2 条序号为警示色；右侧“需要决策 3 项”，下方“详见 P17” |
| 5 指标卡 | 新单保费卡为主色底并带迷你趋势线；达成率卡带满圈进度环；继续率卡顶条为红色，基准条上有 85% 红色标记 |
| 8 区域达成率 | 华东柱为品牌橙、其余灰色；红色虚线“目标 100.0%”；华东上方黑色标注“华东 89.7%，差 10.3pct” |

| 10 方块地图 | 华南最深，华东为浅红；西北、东北为虚线空框；右侧排名华南 → 华中 → 西南 → 华北 → 华东 |
| 11 Excel 联动 | 柱状图两组：新单保费 4.10 / 3.20 / 2.70 / 2.40 / 2.60，目标 3.60 / 2.90 / 2.60 / 2.00 / 2.90；左下“资料来源：branch_dashboard.json · 机构明细” |
| 16 路线图 | 4 条泳道；继续率回访、新激励执行为主色块；菱形里程碑；11 月中部红色“当前”线 |
| 17 总结 | 3 张行动卡（第一张主色底）；下方列出 3 项“需要决策” |

**上市培训.pptx（橙白活力）**：封面白底 + 右上浅橙大圆和橙色伞形图标、底部橙色细带；保障责任页重疾卡为橙色、可选责任为虚线框；
雷达图尊享版为橙色粗线；案例页左侧画像、右侧三步（最后一步橙色）、下方保障结构条；旅程页审核、提交材料为红色痛点，曲线在审核处最低；
问答页每组底部红框列出“避免说”。

**客户说明.pptx（淡雅米橙）**：米白底，米橙强调；倒数第 2 页为“重要提示”，5 条保障型条目。

**通用**：每页动画在出现后自动依次播放；章节页“推入”、其余“淡化”；PowerPoint 里图表数据可编辑。

## C. 端到端（接上 TAP 后）

|---|---|---|
| C1 | “三季度经营数据做个 20 分钟的汇报给管理层” | 先给需求卡片和标题大纲确认；问主题偏好；有执行摘要；数据引用经营看板 Excel；预计时长 ≤ 20 分钟 |
