# 七维质量评分（PPT）

渲染、处理完构建报告后自评。**任何一项低于 4 分就修改后重新渲染**，最多 2 轮。

| 维度 | 5 分 | 3 分 | 1 分 |
|---|---|---|---|
| **故事线** | 只读标题就能听懂；结论先行；管理层汇报有执行摘要；结尾有明确行动和待决策事项 | 结构完整但有话题式标题 | 按资料顺序罗列 |
| **内容准确** | 每个数字有出处；Excel 中有的数据用 `data_from` 引用；案例和演示数据标“示例” | 少量表述不精确或缺来源脚注 | 有无来源的数字 |
| **一页一事** | 每页一个结论，版式证明结论；数据页标题带数字 | 个别页信息过多 | 多页文字堆砌 |
| **图表会说话** | 有目标的画目标线，问题项自动换色并有标注，标题点明问题项 | 图表正确但没有重点 | 图表与结论无关 |
| **视觉呈现** | 留白充足、主色只做强调；版式贴合内容、有变化；强调不超过 2 处 | 版式单调或个别页颜色过重 | 纯文字、花哨或整页铺色 |
| **可讲性** | 每页有口语化备注；预计时长不超过会议时长；动画节奏流畅 | 备注不全或超时 | 没有备注 |
| **合规** | 对外材料有“重要提示”页、无违规用语、示例有标记 | 有“建议修改”项未处理 | 有“必须修改”项 |

## 自查清单

- [ ] 把所有标题连起来读，故事通顺吗？构建报告的“标题体检”都处理了吗？
- [ ] 最重要的 3-6 页标了 `key` 吗？执行摘要里的条目和页码对吗？
- [ ] 每页正文是否在 120 字以内？“文字放不下”的页都处理了吗？
- [ ] 有没有连续 3 页同一版式？有没有一页强调超过 2 处？
- [ ] 每张图表页有“关键发现”或结论条吗？有目标的图画了目标线吗？
- [ ] 预计讲述时长在会议时长以内吗？超了的话，精简版（`--brief`）是否需要一起交付？
- [ ] 最后是不是行动项（谁、做什么、什么时候）和需要决策的事项？
- [ ] 对外材料：有“重要提示”页吗？`review_pptx.py --external` 通过了吗？
- [ ] 【待补充】所在页都在交付说明里列出了吗？
