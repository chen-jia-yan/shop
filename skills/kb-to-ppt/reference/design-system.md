# 设计规范：主题、版面、字体、图标、动画

## 一、7 套主题（同一份内容一键切换，用户自选）

**共同原则：留白为主，主色只做强调。**封面、章节页、结束页都是浅底（白、暖白或米白），主色只用在标题强调字、
细色带、编号、图标和装饰圆上，不整页铺满主色；尊享深绿是唯一的深色主题，供年度总结等需要庄重感的场合。

| 主题 | 封面 / 章节页 | 内容页 | 默认用于 |
|---|---|---|---|
| **orange 橙白活力**（默认） | 白底，右上浅橙大圆 + 橙色图标，底部橙色细带 | 白底，橙色强调 | 产品介绍、培训、方案 |
| **warm 暖阳渐变** | 暖白底，右上浅黄→浅橙渐变圆，底部橙→黄渐变细带 | 暖白底 | 启动会、客户说明会、团队激励 |
| **soft 淡雅米橙** | 米白底，柔和米橙与雾灰圆形 | 米白底，低饱和米橙强调 | 制度宣导、长时间阅读、高净值客户 |
| **minimal 简约商务** | 白底，左侧橙色竖条，右上浅橙圆形 | 白底细线，大量留白 | 工作汇报、项目进展、合规 |
| **premium 尊享深绿** | 深绿底，暖黄同心圆线条，底部橙色细条 | 白底，深绿标题，橙色强调 | 年度总结、高端客户 |
| **blue 信赖科技蓝** | 白底左侧文字，右侧深海蓝→科技蓝色块 + 网格线 | 白底，蓝色主色，问题项用品牌橙 | 经营分析、数字化项目、变更影响分析（与 Excel 蓝色系一致） |
| **teal 康护青绿** | 白底左侧文字，右侧青绿色块 + 波浪 | 白底，青绿主色，问题项用品牌橙 | 健康险、医疗服务、理赔服务 |

- 主题定义在 `tap-config/themes.json` 的 `themes.ppt.styles`，颜色在 `tap-config/brand.json`（新主题用 `sf_` `tl_` `bl_` `tb_` 开头的色），与 Word、Excel 共用；复制一套改名即可新增主题。
- 主要开关：`cover_style`（light 白底圆形 / line 左侧竖条 / panel 右侧色块 / rings 深色同心圆）、`panel_deco`（grid / wave）、
  `cover_light`（封面是否浅底）、`section_dark`（章节页是否深色）、`highlight`（问题项的警示色）、`palette`（图表配色顺序）。
- 默认主题按 `meta.deck_type` 取 `default_by_deck`；用户指定 `meta.theme` 或 `--theme` 时以用户为准。

## 二、页面框架（内容页）

```
┌──────────────────────────────────────────────────────────┐
│ ▍02  章节名                               机构名 简称        │ ← 章节眉标 / 品牌（org.name / org.short）
│ 华东是唯一未完成目标的区域                                  │ ← 标题（结论，26 号，放不下自动缩到 20 号）
│ 各区域目标达成率                                           │ ← 副标题（13 号，数字自动高亮）
│                                                          │
│   主体图示                                │ 关键发现     │ ← 可选右栏
│                                          │              │
│ ┃→ 底部结论条                                            │ ← 可选
│ ────────■■■■■■■■────────────────────────────────────── │ ← 进度条（随页码前进）
│ 机构名 | 短标题                                        07   │
└──────────────────────────────────────────────────────────┘
```

- 16:9，13.333 × 7.5 英寸；左右边距 0.6 英寸。
- 字体：按 `brand.json` 的候选链分别设置中文（cn）、西文（en）、数字（num），中西文分开写入，换电脑不会变成宋体；`--font-cn` 等可临时覆盖，`--font-scale` 整体缩放。
- 字号：封面标题 40、章节标题 40、页面标题 26、小标题 15-17、正文 13-14、注释 9.5-11。
- 自动缩字号：每个文本框按宽高估算，放不下时逐级缩小到下限，仍放不下记入构建报告。
- 颜色比例：主色只用于强调（编号、图标、高亮项、结论条左侧竖条）；结论条、关键发现栏都是浅底；一页内强调不超过 2 处（构建报告会提示）。
- 问题项（未达标、负增长、痛点）用警示色：信赖科技蓝、康护青绿、尊享深绿为品牌橙，其余主题为红色；目标线一律为红色虚线。
- 左下角可放“数据来源”脚注（`source` 或 Excel 联动自动生成），右下角可放“示例样本”标记。

## 三、41 个矢量图标

用原生形状绘制，放大不失真，跟随主题换色，在 PowerPoint 中可编辑。

| 类别 | 图标名 |
|---|---|
| 保险业务 | `shield` 保障　`umbrella` 保险产品　`claim` 理赔　`medical` 医疗　`hospital` 医院　`heart` 健康　`house` 家庭　`car` 车险　`id_card` 身份证件 |
| 人与组织 | `user` 客户　`team` 团队　`chat` 沟通服务　`phone` 热线　`mobile` 线上　`megaphone` 宣导　`award` 荣誉 |
| 数据与目标 | `bar_chart` 数据　`trend_up` 增长　`trend_down` 下降　`pie` 结构　`target` 目标|
| 时间与流程 | `clock` 时效　`calendar` 计划　`flag` 里程碑　`rocket` 启动　`arrow_right` 下一步　`check` 完成　`checklist` 清单 |
| 资金 | `coin` 保费/费用　`wallet` 账户/缴费 |
| 管理与系统 | `lock` 合规　`warning` 风险　`gear` 系统　`search` 查询　`layers` 体系　`link` 协同　`document` 制度文件　`book` 培训　`bulb` 创新　`globe` 覆盖　`star` 亮点 |

不指定 `icon` 时按文字关键词自动匹配（如“理赔”→ claim、“合规”→ lock），同一页内不重复。关键词表在 `tap-config/icons.json`，可自由增删。

## 四、动画与切换

| 元素 | 入场效果 |
|---|---|
| 卡片、要点、流程步骤、时间节点 | 浮入（淡入 + 轻微上移），依次出现 |
| 中心元素、四象限高亮项、VS、大数字 | 缩放 |
| 时间轴、进度条、结论条、分层 | 擦除（自左） |
| 背景装饰、表格、图表 | 淡入 |

- 每页动画在出现后**自动依次播放**，总时长约 2.5 秒；讲的人不需要逐个点击。
- 页面框架（标题、页脚、进度条）不加动画，避免干扰。
- 切换：章节页“推入”，其余页“淡化”。
- 需要导出 PDF 或打印时用 `--no-animation`。
- 一页动画步骤超过 9 个，构建报告会提示拆页。
