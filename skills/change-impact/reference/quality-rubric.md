# 质量评分表

交付前逐项自查。每项 0 / 1 / 2 分，**带 ★ 的任何一项为 0 分不得交付**。总分 ≥ 32（满分 40）为合格。

## A. 准确（不错）

| # | 检查项 | 2 分 | 0 分 |
|---|---|---|---|
| A1 ★ | 版本正确 | 新旧版本号、生效日期与 TAP 元数据一致 | 用了草稿或错版本 |
| A2 ★ | 变化说明与原文一致 | 逐条重大 / 较大都核对过原文 | 有一条与原文不符 |
| A3 | 数值写法 | 全部“由 A 调整为 B”，单位一致 | 只写“调整” |
| A4 | 否定 / 义务判断 | 含义反转、强制 / 可选的判断有原文支持 | 误判方向 |
| A5 ★ | 受影响内容不含被修订文档本身 | 已 `--exclude` | 自己算自己 |

## B. 完整（不漏）

| # | 检查项 | 2 分 | 0 分 |
|---|---|---|---|
| B1 | 变更识别 | 抽查新版 3 处改动都在清单里 | 漏了实质变更 |
| B2 | 影响范围 | 有语料或已用检索语句补查，并写明范围 | 没查却写“无影响” |
| B3 | 对客 / 系统影响 | 每条重大 / 较大都写了受影响对象 | 只写“相关材料” |
| B4 | 合规告知 | 5 项核对都有结论或待确认说明 | 空着 |
| B5 | 措辞调整 | 附录一列全，正文不混入 | 措辞调整当实质变更 |
