## B. 端到端用例（接上 TAP 后）

| # | 用户输入 | 关键检查点 |
|---|---|---|
| B1 | “把我们所有重疾产品的投保规则整理成对比表” | 先检索出完整产品清单再按维度查；用 matrix；每类数据注明来源 |
| B2 | “做个保费试算表给客户用” | 费率表来自知识库；有免责提示；`--external` 质检通过；不编造费率，查不到就停下说明 |
| B3 | “三季度经营数据做成看板” | 看板指标全部为公式引用；比率合计为总额相除；图表标题写结论 |
| B4 | “合规整改事项做个跟踪表，每周要更新” | 甘特 + 下拉状态 + 逾期预警 + 部门统计；每项有责任人和完成日期 |
| B5 | “理赔要哪些材料，做成清单” | 按险种分组；区分必备和如适用；联系方式查不到写【待补充】 |
| B6 | 知识库中两份文件的标准不一致 | 取更新时间新的；备注写明旧标准和来源 |
| B7 | 用户只问“华南三季度保费多少” | 不触发本 skill，交给 qa_advance |
| B8 | 用户要“写成报告” | 不触发本 skill，交给 kb-to-word |
