# 知识生成 Excel

目标是交付一个**打开就能用、改了数字会自己算、拿去开会不用再调格式**的工作簿，而不是把检索结果堆进一张表。

```
① 读懂需求 → 需求卡片（用途、读者、对内/对外、要不要能改能算）
② 设计工作簿 → 工作簿蓝图（几张表、每张表的类型、表之间怎么联动）
③ 按蓝图检索 → 先定对象清单，再按维度检索，记录出处
④ 组装内容 JSON → 数据、公式、图表、校验规则
⑤ 渲染 → .xlsx
⑥ 质检交付 → 质检报告 + 交付说明
```

---

## ① 读懂需求 → 需求卡片

和 kb-to-word 一样先判断，再动手（规则见 `kb-to-word/reference/requirement-analysis.md`）。Excel 额外要判断两件事：

| 项 | 判断 | 影响 |
|---|---|---|
| **要不要能算** | 用户会改数字看结果吗？（试算、目标测算、跟踪进度） | 需要 → 用录入格 + 公式；不需要 → 静态数值即可 |
| **要不要持续更新** | 是一次性汇总，还是每周/每月有人更新？ | 持续更新 → 下拉校验、冻结表头、筛选、自动预警，留空行 |

```
📋 需求卡片
用途：经营会看板｜读者：管理层｜对内｜要能算：是（改明细自动更新）｜持续更新：每季度
风格：尊享深色｜重点：区域达成、继续率预警｜口径：2026 年 Q3
```

## ② 设计工作簿 → 工作簿蓝图

从 `reference/workbook-patterns.md` 选最接近的模式，按需求改造。蓝图要写清：

- **每张工作表的类型**（8 种，见 `reference/sheet-types.md`）和它回答的问题
- **表之间的联动**：哪些数在明细表录入，哪些在看板/汇总表用公式引用
- **图表**：每个图回答一个问题，标题写结论

原则：
- **一个工作簿一个主题**，3-6 张表为宜；第一张是“说明”（cover），最后一张可以是“口径说明”（notes）。
- **数据只录一次**：汇总、占比、达成率、排名都用公式算，不要手工再填一遍。
- **对象 × 维度**：明细表每行一个对象（机构、产品、事项），每列一个维度；列数控制在 10 列以内，超出时拆表。
- **对外文件**（发给客户）只放客户需要的列，不放内部价格、费用率、员工信息。

## ③ 按蓝图检索

检索方法、证据台账同 `kb-to-word/reference/retrieval.md`，表格类有两点不同：

1. **先确认对象清单，再按维度检索。** 先查“一共有哪些产品/机构/事项”，确认没有漏行；再每个维度检索一次，覆盖所有对象。比逐个对象去查省很多次数。
2. **单元格级出处**：数字必须能在证据台账找到；查不到的格子填【待补充：XX】（渲染后自动标橙黄色），不用推测值填。

## ④ 组装内容 JSON

格式见 `reference/sheet-types.md`，设计与公式规范见 `reference/design-standards.md`。要点：

- 能用公式的地方用公式，用 `{表名.列名}` 跨表引用（看板可以引用排在后面的明细表）。
- 逐行计算用列级 `formula`（如 `=IFERROR({@新单保费}/{@目标},0)`）；**所有除法都包 IFERROR**。
- 合计行用 `total: "sum"`（生成 SUBTOTAL，筛选后自动只算可见行）；比率类合计写公式（总保费 ÷ 总目标），不要对比率求和或简单平均。
- 枚举列给 `options`（生成下拉），阈值列给 `rule`（条件格式），进度类给 `databar`。
- 图表的 `title` 写结论（“华南同比增速领先，华东为负”）。

## ⑤ 渲染

```bash
pip install -U openpyxl
python scripts/render_xlsx.py content.json out/文件名.xlsx
python scripts/render_xlsx.py content.json out/文件名.xlsx --style premium   # 换风格
```

- 退出码 2：内容校验不通过（工作表名非法/重复、列数不对、缺字段），按提示改 JSON。
- 退出码 3：文件已生成，但有公式引用或图表解析失败（如引用了不存在的列），按提示修正后重跑。
- 打开时 Excel 会自动重算全部公式。

## ⑥ 质检交付

```bash
python scripts/review_xlsx.py out/文件名.xlsx [--external] [--final] [--recalc]
```

1. **脚本检查**：未解析的引用、引用不存在的工作表、没有 IFERROR 的除法、占位符、合规用语（`--external`）、对外试算表的免责提示；装了 LibreOffice 时加 `--recalc` 检查 `#REF!` `#DIV/0!` 等错误值。有“必须修改”就回到 ④。
2. **自评**：按 `reference/quality-rubric.md` 六项打分，任何一项低于 4 分修改后重新渲染，最多 2 轮。
3. **交付说明**（在对话中）：
   - 有哪几张表、各自用途；哪些格子可以改（黄色录入格）、改了会联动哪里
   - 主要依据的知识库文档
   - 【待补充】【请确认】的数量和位置（工作表 + 单元格）
   - 对外文件提醒：正式使用前按公司流程审核；试算结果以投保系统为准

## 不要做的事

- 不要把所有内容塞进一张大表；也不要为了“丰富”加用不上的图表。
- 不要在公式能算的地方手工填数，不要对百分比列直接求和。
- 不要编造费率、价格、联系方式；示例里的数据只在 `examples/` 中使用。
- 对外文件不要出现收益承诺、与存款类比、绝对化用语。
