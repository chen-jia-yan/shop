# 版式、数字与公式规范

## 一、三套风格

| 风格 | 表头 | 隔行 | 指标卡 | 适用 |
|---|---|---|---|---|
| **classic 经典橙白** | 橙底白字 | 极浅橙 | 浅橙底 + 橙色顶条 | 产品对比、客户清单、试算 |
| **premium 尊享深色** | 深绿底白字 | 浅灰 | 深绿底白字 + 黄色顶条 | 经营看板、管理层报表 |
| **minimal 简约白** | 浅灰底黑字 + 橙色底线 | 无 | 白底 + 橙色顶条 | 整改跟踪、制度台账、检查表 |

共同规范：
- 关闭网格线；第 1 行品牌色条，第 2 行标题（16 号加粗），第 3 行副标题/口径。
- 字体微软雅黑；数字 Arial；正文 10 号，表头 10 号加粗。
- 工作表标签着色：说明页和数据表用风格主色，口径说明用灰色，试算用橙色。
- 打印：A4，列多时横向，按页宽缩放，每页重复表头，页脚“第 X 页 / 共 Y 页”。

## 二、单元格角色（全工作簿统一，说明页有图例）

| 角色 | 样式 | 含义 |
|---|---|---|
| 录入格 | 黄底、棕色边框 | 可以修改；试算表中只有这些格子解锁 |
| 公式格 | 深绿色字 | 自动计算，不要手工覆盖 |
| 待补充 | 橙黄底、加粗 | 知识库中没查到，需要人工补充或确认 |

## 三、数字格式

| 数据 | 格式 | 说明 |
|---|---|---|
| 金额（元） | `money` → `#,##0` | 保费、费用 |
| 万元 / 亿元 | `wan` → `#,##0.00`、`yi` → `0.00` | 单位写在表头 |
| 比例 | `pct` → `0.0%` | 录入时填小数（0.881），不要填 88.1 |
| 同比 | `delta` → `▲0.0%` / `▼0.0%` | 配合 `rule: sign` 着色 |
| 百分点 | `delta_pt` → `▲0.0pct` | 继续率、赔付率等比率的变化 |
| 日期 | `date` → `yyyy-mm-dd` | 录入为日期而不是文字，才能排序和计算 |

**单位只写在表头**（“新单保费（亿元）”），单元格里只放数字，这样才能计算。

## 四、公式与联动

1. **数据只录一次。** 汇总、占比、达成率、排名、统计都用公式引用明细。
2. **除法一律包 IFERROR**：`=IFERROR(A/B,0)`。质检会提示没有包的除法。
3. **合计行用 SUBTOTAL**（`total: "sum"` 自动生成），筛选后只算可见行。
4. **比率类合计写公式**：总达成率 = 总保费 ÷ 总目标，不是各行达成率的平均。
5. **排名用公式**：LARGE + INDEX/MATCH，数据变了排名自动变。
6. **按日期预警用 TODAY()**：逾期、到期提醒在每次打开时自动更新。
7. **查找用 INDEX/MATCH**，不用 VLOOKUP（列顺序变了不会错）；按区间取值时首列升序、MATCH 第三个参数为 1。
8. **不引用整列**（如 `A:A`），引用明确的数据范围，避免计算慢和误统计。

## 五、条件格式用法

| 场景 | 规则 |
|---|---|
| 同比、增减 | `sign`；赔付率、费用率等“下降为好”的加 `good: "down"` |
| 低于目标、超出标准 | `lt` / `gt` + `style: bad` |
| 状态为“预警”“高” | `text` |
| 进度、产能 | `databar` |
| 大量数值的分布 | `scale`（慎用，一张表最多一列） |

一张表的条件格式不超过 3 种，否则重点就不突出了。

## 六、图表

- 每张图回答一个问题，标题写结论。
- 单系列用主色；需要突出一项时用 `highlight`（一项橙色、其余灰色）。
- 分类超过 8 个用条形图（`bar`），不用柱状图。
- 饼图/环形图不超过 6 项，其余合并为“其他”。
- 规模和增速放一起用 `combo`，增速放右轴。
