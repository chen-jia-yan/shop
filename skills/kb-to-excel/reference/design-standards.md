# 表格样式、数字与公式规范

原则：**像一张好用的表，而不是一页文档。**结构清楚、颜色克制、每个颜色都有含义；不做封面、海报式色块、大标题横幅、合并单元格排版。

## 一、三套色系（结构一致，只换颜色）

颜色全部来自 `tap-config/brand.json`（`tb_*`）和 `themes.json → excel.styles`，不在脚本里写死。

| 色系 | 强调色 | 表头 | 适用 |
|---|---|---|---|
| **blue 蓝色系**（默认） | 科技蓝 `tb_blue` | 极浅蓝灰底 + 蓝色下边线 | 台账、跟踪、看板、对比、试算 |
| **soft 淡色系** | 雾蓝 `tb_soft` | 近白底 + 雾蓝下边线 | 名单、制度汇总、长时间阅读的表 |
| **orange 橙色系** | 品牌橙 `primary` | 浅灰底 + 橙色下边线 | 需要和对外品牌物料保持一致时 |

`meta.kind` 决定默认色系（`themes.json → excel.default_by_kind`），`meta.style` 或命令行 `--style` 可覆盖。新增色系只需在 themes.json 里加一组 styles。

共同规范：
- 第 1 行是表名（13 号加粗），第 2 行是表头；数据从第 3 行开始。不留品牌色带、不留空行。
- 表头 10 号加粗，按字段类型区分底色和下边线：普通字段浅底 + 强调色线、公式与提醒标记浅绿灰底、智能字段浅紫底、链接字段浅底、辅助列灰底。表头批注写类型、必填、口径和来源。表头文字就是字段名（也是结构化引用的列名），不要加符号或换行。
- 隔行极浅底色、浅网格线，关闭工作表网格线；数字列右对齐、日期和单选居中、长文本换行。
- 冻结表头和主键列；数据表自带筛选按钮（Excel 表格对象）。
- 字体取 `brand.json` 的 fonts（中文 cn、数字 num、公式 mono），可在配置里整体更换。
- 工作表标签颜色：数据表强调色、视图中间色、仪表盘深色、规则与参数灰色。

## 二、单元格角色（全工作簿统一，“使用说明”里有样例格）

| 角色 | 样式 | 含义 |
|---|---|---|
| 录入格 | 淡黄底 | 可以修改，例如状态、承办人、参数 |
| 公式格 | 深青绿字 | 自动计算，不要手工覆盖 |
| 智能生成 | 紫色字、浅紫表头，批注写依据 | 由原文生成，待人工确认；不替代原文 |
| 待补充 | 橙黄底加粗 | 知识库中没查到 `【待补充：XX】` / 需确认 `【请确认：XX】` |
| 提醒 · 严重 | 浅红底红字 | 规则 level = bad，如超时、逾期 |
| 提醒 · 注意 | 浅黄底棕字 | level = warn，如临近、未分派、缺信息 |
| 提醒 · 待复核 | 浅紫底紫字 | level = info，如智能列与人工登记不一致 |
| 状态 | 绿 / 紫 / 灰 胶囊色 | 字段 `styles` 指定，如已结案绿、处理中紫、待处理灰 |
| 辅助列 | 灰底灰字，折叠隐藏 | 视图和仪表盘用的匹配、序号，不要删除 |

一张表上同时出现的提醒颜色不超过 3 种；状态色和提醒色不要用在同一列。

## 三、字段类型与数字格式

| 类型 | 默认格式 | 说明 |
|---|---|---|
| `number` | `#,##0` 或按 `format` | 单位写在字段名里：“新单保费（亿元）” |
| `money` | `money` → `#,##0` | 元；`money2` 两位小数 |
| `percent` | `pct` → `0.0%` | 录入小数 0.881，不要录 88.1 |
| `date` | `date` → `yyyy-mm-dd` | 必须是日期值，才能排序、计算、做趋势 |
| `select` / `bool` | 文本，居中 | 下拉校验，选项集中在“参数”表 |
| `longtext` | 文本，换行，宽列 | 原文完整保留 |
| `link` | 蓝色下划线 | 显示文字可用 `display` |

其他格式：`wan`（万元）、`yi`（亿元）、`pct0`、`ratio`（`0.0`）、`month`、`delta`（▲▼ 同比）、`delta_pt`（百分点）。
**单元格里只放数字，单位放字段名或数字格式**（仪表盘指标的单位写进数字格式，值仍可计算）。

## 四、公式与联动

1. **数据只录一次。** 视图、仪表盘、提醒都用公式引用原始数据表；不复制、不手填。
2. **结构化引用。** 数据表是 Excel 表格对象：本行 `tbl1[[#This Row],[字段]]`，整列 `tbl1[字段]`。表格新增行时公式和统计范围自动扩展。
3. **兼容旧版 Excel。** 只用 COUNTIFS / SUMIFS / AVERAGEIFS / INDEX / MATCH / IFERROR / TODAY / TEXT 等通用函数；**不用** FILTER、SORT、SORTBY、UNIQUE、XLOOKUP、LET、LAMBDA。视图的筛选和排序靠隐藏辅助列（匹配标记 + COUNTIFS 排名）实现。
4. **除法一律包 IFERROR。**质检会提示没有包的除法。
5. **比率类汇总写公式**：总达成率 = 总保费 ÷ 总目标，不是各行达成率的平均。
6. **阈值放参数。**时限、预警线写在“参数”表，公式里 `{param.键}` 引用。
7. **按日期预警用 TODAY()**，每次打开自动更新；在 `meta.disclaimer` 写明。
8. **每个公式字段写一句 `desc`**，说明含义和口径，显示在表头批注和“字段说明”里。
9. **洞察句用公式拼接**：`="超时未结 "&COUNTIFS(...)&" 件"`，数据变了句子跟着变；不写死结论。

## 五、条件格式

| 场景 | 做法 |
|---|---|
| 超时、逾期、缺信息 | `rules`：命中写入“提醒标记”并给指定字段着色，可在“提醒规则”表停用 |
| 状态、等级 | 字段 `styles` |
| 必填为空 | 自动标黄 |
| 智能列与人工不一致 | `ai.check`，自动标紫 |
| 进度、天数、产能 | `databar` |
| 交叉分布 | 仪表盘 `heatmap`（色阶） |

条件格式不能用结构化引用，渲染时自动转成 A1 写法（列绝对、行相对），不要手写。

## 六、仪表盘

- 风格：白色卡片面板 + 深色标题栏，KPI 卡顶部渐变细条、数字大号等宽字体、可加进度圆环；整体是“驾驶舱”而不是文档。
- 顺序：指标（现在怎样）→ 洞察（说明了什么）→ 趋势（怎么变的）→ 分布与分组（问题在哪）→ 异常清单（先处理谁）。
- 指标 2–8 个，每个都要有 `note` 给出对比或构成；需要警示的加 `alert`。
- 图表数据放右侧计算区（公式），图表引用计算区或数据表，不引用手填数字。

## 七、图表

- 每张图回答一个问题，标题写结论（“华南同比增速领先，华东为负”）。
- 单系列用强调色；突出一项用 `highlight`（一项强调色、其余灰色）。
- 分类超过 8 个用条形图；饼图 / 环形图不超过 6 项；规模 + 增速用 `combo`，增速放右轴。
- 配色取当前色系的 `palette`，三套色系自动切换。

## 八、打印

A4，列多时横向、按页宽缩放，每页重复表头；页脚“第 X 页 / 共 Y 页”。辅助列和计算区不打印。
