# 七维质量评分（Excel）

渲染并通过脚本质检（`review_xlsx.py --content`）后自评。**任何一项低于 4 分就修改后重新渲染**，最多 2 轮。
“数据完整”是一票否决项：低于 4 分不得交付。

| 维度 | 5 分 | 3 分 | 1 分 |
|---|---|---|---|
| **数据完整** | 检索到的记录全部入表，字段全部保留，原文一字不改；行数、字段数与需求卡片一致 | 个别字段被合并或改写，但记录没少 | 用摘要代替原始数据，或少了记录 |
| **数据准确** | 每行有来源；数字、日期是可计算的值；查不到的标【待补充】 | 少量格子缺出处或日期是文本 | 有推测或编造的数字 |
| **字段设计** | 一行一件事、主键唯一；类型正确（日期、单选、数字）；阈值放参数；公式字段有说明 | 类型基本正确，少量该下拉的没下拉 | 一个格子塞多件事，或用合并单元格 |
| **视图与分析** | 视图回答“先处理谁”，仪表盘回答“整体怎样、问题在哪”，提醒规则覆盖超时和缺失；全部由公式驱动 | 有汇总但部分是手填数字，或缺关键提醒 | 改了数据，视图和仪表盘不变 |
| **智能列** | 标注依据和日期；原文列保留；与人工字段有对照 | 有标注但无对照 | 智能内容覆盖了原文，或没有标注 |
| **易用与样式** | 表格原生风格、色系统一；冻结、筛选、下拉、录入格清楚；使用说明可跳转；新旧版 Excel 都能打开计算 | 格式基本统一，缺冻结或说明 | 像文档或海报；或用了新版专有函数 |
| **合规** | 对外文件无违规用语、无内部信息、试算有免责提示；个人信息已脱敏 | 有“建议修改”项未处理 | 有“必须修改”项 |

## 自查清单

- [ ] 数据表记录数 = 检索到的记录数（`expect_rows`）？质检 `--content` 没有报缺行、缺字段、原文被改？
- [ ] 原文类字段（问题描述、条款原文、处理意见）是否完整写入，摘要是另外一列？
- [ ] 日期是日期值、百分比是小数？有没有对百分比列直接求和或平均？
- [ ] 改一个原始数据（比如把一件工单改成已结案），视图、提醒标记、仪表盘、洞察句子都跟着变吗？
- [ ] 公式里有没有 FILTER / SORT / UNIQUE / XLOOKUP / LET？（不应有）
- [ ] 所有除法都包了 IFERROR 吗？阈值都在参数表吗？
- [ ] 每条提醒规则在“提醒规则”表里都能看到命中数、可以停用吗？
- [ ] 智能列的表头批注写了依据和日期吗？交付说明里提醒了待人工确认吗？
- [ ] 图表标题写的是结论吗？
- [ ] 【待补充】【请确认】的位置都在交付说明里列出了吗？
