# 8 种保险业务工作簿模式

每种模式给出：适用场景 → 推荐工作表组合 → 联动关系 → 注意事项。按需求删减改造。

## 1. 产品 / 方案对比 + 试算（对外为主）
**场景**：向客户说明几个产品或版本的差别，并现场试算保费。
**组合**：说明 → 对比矩阵（matrix）→ 试算（calculator，含费率查找表）
**联动**：试算结果由录入格 + 费率表 INDEX/MATCH 计算。
**注意**：费率必须来自知识库费率表；必须写“试算结果仅供参考，以保险合同为准”；对比矩阵中推荐项要写适用人群，不写“最好”。

## 2. 经营看板（对内）
**场景**：月度/季度经营会。
**组合**：说明 → 看板（dashboard）→ 机构明细（table）→ 产品结构（table）→ 趋势（table）→ 口径说明（notes）
**联动**：看板指标卡全部引用明细表合计行；排名用 LARGE/INDEX/MATCH 动态生成；图表引用明细表。
**注意**：比率类合计用公式（总额相除），不要平均；“下降为好”的指标（赔付率、费用率、投诉率）在条件格式里反向着色。

## 3. 整改 / 项目跟踪（对内，持续更新）
**场景**：合规整改、项目里程碑、系统上线计划。
**组合**：说明 → 甘特跟踪（gantt）→ 部门统计（table，COUNTIF 引用跟踪表）→ 问题清单（table）
**联动**：部门统计、汇总条全部由跟踪表自动计算；逾期和到期预警按 TODAY() 计算。
**注意**：状态用下拉；每项都要有责任人和完成日期；整改措施写具体动作。

## 4. 材料 / 检查清单（对内或对外）
**场景**：理赔材料、投保材料、上线检查、审计准备。
**组合**：清单（checklist），可按险种或环节分组；需要时加说明页。
**联动**：顶部进度由勾选状态自动计算，显示必备项还差几项。
**注意**：区分“必备”和“如适用”；对外版本写明以受理时告知为准。

## 5. 参数 / 政策汇总台账（对内）
**场景**：把散落在多篇文档里的规则汇总，如各产品投保规则、各地区报销标准、各渠道佣金政策。
**组合**：说明 → 汇总表（table 或 matrix）→ 口径说明（注明每类数据出处和更新日期）
**联动**：一般为静态数据；如有标准值和实际值，用条件格式标出超标项。
**注意**：每行或每类注明来源文档与更新时间；新旧规定冲突时以新为准并在备注中写明。

## 6. 费用 / 预算测算（对内）
**场景**：活动预算、培训费用、项目投入测算。
**组合**：试算（calculator）或明细表（单价 × 数量 公式列 + 合计）→ 汇总
**联动**：单价、数量为录入格，金额和合计为公式。
**注意**：标准单价来自知识库中的费用管理办法；超标准的用条件格式提示。

## 7. 名单 / 通讯录（对内）
**场景**：项目联系人、各机构对接人、讲师名单。
**组合**：明细表（table），带筛选和冻结。
**注意**：只使用知识库中有权限查看的信息；手机号等个人信息仅在确有需要时放入，对外文件一律不放。

## 8. 培训 / 考试台账（对内）
**场景**：培训计划、出勤、考试成绩。
**组合**：明细表（成绩、是否通过公式列）→ 统计表（按机构 COUNTIF/AVERAGEIF）→ 看板（可选）
**联动**：是否通过 `=IF({@成绩}>=60,"通过","未通过")`；统计表引用明细。
**注意**：通过线等规则来自培训管理办法，查不到时写【请确认】。
