# 保险写作规范与合规底线

> 本文件中的禁用词与必备要素按行业常见口径整理，上线前请合规部审定。审定后修改 `tap-config/compliance.json`（banned、required 等），Word、Excel、PPT、变更影响分析四个 skill 同时生效。

## 一、合规底线（对外文档必须遵守）

| 类别 | 不能写 | 可以这样写 |
|---|---|---|
| 收益承诺 | 保本、稳赚、零风险、保证收益、高收益 | 保证利益以合同约定为准；分红/万能账户收益**不保证**，演示利率不代表实际收益 |
| 存款类比 | 比存银行划算、可替代储蓄、理财产品 | 保险产品不同于银行存款，提前退保可能产生损失 |
| 绝对化 | 最好、第一、唯一、100% 理赔、一定赔 | 符合合同约定的保险责任，按约定给付 |
| 夸大保障 | 什么都赔、无条件赔付、带病也能保 | 保障范围以保险合同条款为准；投保前需如实告知健康状况 |
| 诱导 | 限时抢购、马上停售、最后机会 | （如确需告知停售）本产品将于 X 年 X 月 X 日起停止销售 |

**必备要素**（产品资料、客户方案）：
1. 犹豫期（时长、犹豫期内退保的处理）
2. 等待期（时长、等待期内出险的处理）
3. 责任免除（列出主要情形，并说明“完整内容见合同条款”）
4. “具体以保险合同条款为准”的声明
5. 风险提示（提前退保损失、如实告知义务等）

## 二、通用写作规范

**结论先行**：每章第一句就是结论。读者只读每章第一段也能抓住全文要点。

**具体**：
| 模糊 | 具体 |
|---|---|
| 尽快办理 | 收到材料后 <N> 个工作日内作出核定（N 以知识库为准） |
| 保额较高 | 基本保额 <金额> 万元 |
| 大部分客户 | 约 <比例>% 的客户（来源：<出处>） |
| 相关部门 | 理赔部 |

**一致**：同一概念全文用同一个词（不要“被保险人”“受保人”混用）；数字格式一致（金额统一“万元”或“元”）。

**术语**：对外文档第一次出现专业术语时用一句话解释，或放进术语表；对内文档可直接使用。

**数字**：
- 金额：万元以上用“万元”，保留 1-2 位小数；亿元同理。
- 比例：同比、环比写清楚；百分点用“pct”或“个百分点”，不要和“%”混用。
- 时间：写明“自然日”还是“工作日”。

**语气**：
- 对客户：礼貌、简明，用“您”；避免“必须”“禁止”等命令式（法定义务除外）。
- 制度：用“应”“须”“不得”，不用“尽量”“原则上”。
- 汇报：判断明确，“增速放缓主要因为 A”优于“可能有多方面原因”。

## 三、拒绝空洞：五条硬标准

渲染时脚本会做“内容体检”（规则在 `tap-config/rules.json` 的 `rules.word.content`），但标准要在写的时候就做到：

1. **每章至少一个可核对的事实**：数字、时限、金额、条款编号、具体条件或真实（脱敏）案例，且都在证据台账里有出处。数据类文档（经营分析、项目方案、变更影响）每章必须有数字。
2. **每段三要素**：结论（是什么）+ 依据（数字、条款、事实）+ 影响或做法（所以怎样 / 读者该做什么）。只有结论没有依据的段落，要么补依据，要么删掉。
3. **不用套话**：“进一步加强、全面提升、高度重视、多措并举、及时、尽快、相关部门”这类词，换成具体的动作、标准、时限和责任人。一段里出现 3 个以上且没有数字，体检会提示。
4. **要点不只写关键词**：“及时报案、材料齐全、如实告知”这种列表读者拿到没法用，每条补一句“怎么做 / 标准是什么”。
5. **给例子**：产品资料至少一个投保或理赔举例（年龄、保额、交费期、给付金额）；培训手册每条规则配一个案例或易错点；制度对容易误解的条款给一个情形说明。

| 空洞写法 | 改成 |
|---|---|
| 进一步加强继续率管理，全面提升服务质量 | 11 月底前对 13 个月内未续费的 2,860 件保单逐单回访，目标继续率回升到 88%（客户服务部牵头） |
| 及时报案，尽快提交材料 | 确诊或住院后 <N> 日内报案；材料齐全后 <N> 个工作日内作出核定（N 以条款为准） |
| 本产品保障全面，适合各类人群 | 覆盖 120 种重疾、25 种中症、50 种轻症；更适合有家庭责任、需要收入补偿的客户 |
| 华东区域表现欠佳，需持续关注 | 华东同比 −4%，是唯一负增长的区域，主要因为有效人力环比减少 6% |

**查不到就写【待补充：XX】**，不要用套话把空位填满；占位比空话更诚实，也更容易在交付前补齐。

## 四、从知识库到文档：改写要点

知识库原文往往是写给另一类读者的，要按本次读者重写：

| 原文是 | 要写成 | 怎么改 |
|---|---|---|
| 条款原文 | 产品说明书 | 拆成“保什么/不保什么/怎么赔”；条款编号放来源里 |
| 内部操作规程 | 客户理赔指引 | 去掉内部审核环节；只保留客户要做的事和时效 |
| 制度 | 培训手册 | 每条规则配一个例子和一个易错点 |
| 多份周报 | 季度分析 | 合并数字，提炼趋势和原因，不按周罗列 |

**引用不等于照抄**：可以引用关键句（用 quote），但大段内容必须重新组织。
