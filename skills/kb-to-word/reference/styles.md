# 风格、字体与版式规范（可自行增加风格）

风格定义在 `tap-config/themes.json` 的 `themes.word.styles`，颜色在 `tap-config/brand.json`（蓝色系用 `tb_` `wd_` 开头的色，与 Excel、PPT 蓝色系一致）；复制一套改名即可新增风格，`--style 新名字` 直接可用。

## 一、六套风格

**默认是淡色系与蓝色系**，橙色系保留为可选。蓝色系、淡色系的封面都是浅底，主色只用于编号、标题线、表头底线和高亮项，不大面积铺色。

| 风格 | 封面 | 一级标题 | 表格 | 默认用于 |
|---|---|---|---|---|
| **soft 淡雅蓝**（默认） | 白底，左侧一深一浅两条蓝灰竖色带，大量留白 | 蓝灰编号 + 石板灰标题 + 浅色细下划线 | 三线表（上下粗线、表头下细线，无竖线） | 产品资料、客户方案、理赔指引、培训手册、客户告知函 |
| **blue 商务蓝** | 顶部蓝色细条 + 浅蓝色块，深海蓝标题；下方信息表 | 左侧蓝色竖条 + 浅蓝底纹 | 浅蓝表头 + 蓝色底线，极浅隔行底纹 | 经营分析、项目方案、管理制度、合规报告、核保说明、变更影响分析 |
| **navy 深蓝稳重** | 整版深海蓝，白字大标题，冰蓝点缀 | 深蓝标题 + 深蓝下划线 | 深蓝底白字表头 | 年度报告、董事会/管理层正式报告 |
| classic 经典橙白 | 顶部满宽橙色色带 | 橙色编号 + 橙色下划线 | 橙底白字 | 需要与橙色品牌物料保持一致时 |
| premium 尊享深绿 | 整版深绿，暖黄点缀 | 深绿标题 + 黄色下划线 | 深绿底白字 | 高端客户方案 |
| minimal 简约白（橙） | 白底，顶部橙色粗线 | 黑色标题 + 橙色下划线 | 浅灰表头 + 橙色底线 | 橙色系的制度类文件 |

每套风格写全同一组键，主要开关：

| 键 | 可选值 | 作用 |
|---|---|---|
| `cover` | `side` 侧条 / `band` 顶部色块 / `full` 整版 / `line` 细线 | 封面版式 |
| `h1_style` | `bar` 左竖条 + 浅底纹 / `rule` 下划线 | 一级标题样式 |
| `table_style` | `three_line` 三线表 / `tint` 浅表头 + 主色底线 / `filled` 实色表头 | 表格样式 |
| `accent` `accent_dark` `accent_light` `accent_pale` | 颜色 | 主色及深浅（编号、条形、高亮、卡片底） |
| `deep` `deep_mid` `deep_pale` | 颜色 | 深色（标题、问答“答”、执行摘要标题栏） |
| `good` `bad` | 颜色 | 涨跌、达标与否的颜色 |
| `palette` `chart_hi` | 颜色列表 / 颜色 | 图表配色、高亮图主色 |

## 二、字体：两套方案，按文档类型自动选

| 方案 | 标题 | 正文 | 西文 / 数字 | 默认用于 |
|---|---|---|---|---|
| **modern** | 微软雅黑（加粗） | 微软雅黑 | Arial | 方案、报告、产品资料、培训、理赔指引等大多数文档 |
| **formal** | 黑体 | 宋体，首行缩进 2 字 | Times New Roman | 管理制度、通知、合规报告等正式公文 |

- 中文、西文、数字分开写入，换电脑也不会变成默认字体；数字列、指标卡、页码用数字字体，对齐整齐。
- 方案定义在 `brand.json` 的 `font_presets`，按类型选择在 `rules.json` 的 `rules.word.font_preset`；可用 `meta.font_preset` 或 `--font-preset formal` 指定，`--font-cn` 等单独覆盖某一种字体时优先级最高。
- 图表图片总是用黑体系（标题字体），不用宋体。

## 三、版式规范

- **纸张**：A4 纵向；页边距上 2.6、下 2.4、左右 2.5 cm；版心宽 16.0 cm。表格写的列宽会按比例贴合版心。
- **字号**（常用公文字号）：封面标题 28、一级标题 16（三号）、二级 14（四号）、三级 12（小四）、正文 10.5（五号）、表格 9.5、题注与注释 9、页眉页脚 8。
- **行距与段距**：正文 1.5 倍、段后 6 磅；一级标题段前 24 / 段后 12，二级 16 / 8，三级 10 / 4；表格内 1.3 倍。
- **页眉**：左侧“机构名 | 短标题”，右侧“密级：内部”，下方细线。
- **页脚**：有文档编号时左侧“编号　版本”、右侧“第 X 页 / 共 Y 页”；没有编号时页码居中。正文从第 1 页开始编号，封面和目录不编号。
- **编号**：一级“一、”，二级“1.1”，三级“1.1.1”；图表按“图 1”“表 1”顺序编号。制度类可关闭自动编号（`numbering: false`），标题直接写“第一章　总则”。
- **表格细节**：数字整列右对齐（表头随列对齐）；表头名含“同比、环比、变化、增减”等的列，正数绿色、负数红色（`delta_good: "down"` 时反过来）；合计行浅底 + 上方细线。
- **底纹比例**：浅底纹只用在一级标题条、表头、要素表名称列、数据卡片、提示框；一页内带底色的元素不超过 3 个。
- **颜色比例**：主色只做强调，正文一律深灰黑色；问题项（未达标、负增长）用警示红，不用主色。

## 四、怎么选

1. 用户指定了就用用户的。
2. 没指定：按文档类型默认（`themes.word.default_by_type`），未列出的类型用淡雅蓝。
3. 正式对外报告、年度报告 → navy；需要和橙色宣传物料成套 → classic。
4. 同一系列文档（如同一产品的说明书和理赔指引）用同一套风格。
