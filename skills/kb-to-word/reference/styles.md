# 三套富卫风格

所有色值集中在 `scripts/themes.py`，品牌部核对后改一处全局生效。

| 风格 | 封面 | 标题 | 表头 | 适用 |
|---|---|---|---|---|
| **classic 经典橙白** | 顶部满宽橙色色带，白字标题，黄色点缀线；下方信息表 | 橙色编号 + 橙色标题 + 橙色下划线 | 橙底白字，浅橙隔行 | 产品资料、客户方案、理赔指引（客户自助版）、培训 |
| **premium 尊享深色** | 整版深绿，白字大标题，暖黄点缀 | 橙色编号 + 深绿标题 + 黄色下划线 | 深绿底白字，浅灰隔行 | 高端客户方案、管理层报告、年报 |
| **minimal 简约白** | 白底，顶部橙色粗线，大量留白 | 橙色编号 + 黑色标题 + 橙色下划线 | 浅灰底黑字 + 橙色底线，无隔行 | 管理制度、操作指引、合规报告、核保说明 |

## 共同规范

- **纸张**：A4 纵向；页边距上 2.6、下 2.3、左右 2.3 cm；正文宽 16.4 cm。
- **字体**：中西文统一微软雅黑；KPI 大数字用 Arial。
- **字号**：正文 10.5 磅（五号），一级标题 18，二级 14，三级 12，表格 9.5，题注 9，页眉页脚 8。
- **行距**：正文 1.4 倍，段后 6 磅。
- **页眉**：左侧“富卫人寿 | 短标题”，右侧密级，下方细线。
- **页脚**：居中“第 X 页 / 共 Y 页”，正文从第 1 页开始编号，封面和目录不编号。
- **编号**：一级“一、”，二级“1.1”，三级“1.1.1”；图表按“图 1”“表 1”顺序编号。
- **颜色使用比例**：橙色只用于强调（编号、标题线、高亮），不要大面积铺色；一页内彩色元素不超过 3 个。

## 怎么选

1. 用户指定了就用用户的。
2. 没指定：按文档类型默认（themes.py 的 `DEFAULT_STYLE_BY_TYPE`）。
3. 读者是高端客户或管理层 → premium；正式制度或合规 → minimal。
4. 同一系列文档（如同一产品的说明书和理赔指引）用同一套风格。
