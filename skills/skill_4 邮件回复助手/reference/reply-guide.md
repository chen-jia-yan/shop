# 回复写作指南

> ⚠️ 待补充：公司邮箱域名（用于判断内部/外部）、公司对外邮件的署名格式。

```
COMPANY_DOMAINS = example.com
```

多个域名用逗号分隔。发件人邮箱域名不在列表里的，按外部邮件处理。

## 结构

1. **称呼**：外部用"X 总""X 经理""X 先生/女士"（来信署名里有职务就用职务）；内部同事用名字或"X 老师""X 哥/姐"按公司习惯，拿不准就用"您好"
2. **开头一句**：回应来意，不要长篇客套。"关于您询问的报销时限，回复如下："
3. **正文**：逐条回应，事项 2 条以上用编号；每条先给结论，再给必要的说明
4. **下一步**：需要对方做什么、我们会做什么、什么时候
5. **结束语**：外部"如有疑问，欢迎随时联系。"；内部可以省略或"有问题随时找我"
6. **署名**

## 语气

| 来信方 | 语气 | 注意 |
|---|---|---|
| 外部客户 | 正式、礼貌、简洁 | 不用内部术语；不出现内部信息；不做未授权的承诺 |
| 外部供应商 | 正式、明确 | 写清要求和时间节点 |
| 内部同事 | 友好、直接 | 可以简短；可以引用内部文档名 |
| 领导 | 正式、结论先行 | 第一句就是结论 |
| 投诉/不满 | 先理解、后事实 | 先致歉或表示理解；不争论；给出解决办法或处理时间 |

## 三种常见情况的写法

**能直接回答**
> 根据公司差旅费报销规定，报销须在出差结束后 15 个工作日内提交，逾期需要财务总监特批。

**需要用户确认（不替用户决定）**
> 关于延期提交的申请，【请确认：是否同意延期，以及是否已获财务总监特批】。
> 草稿外提醒用户："延期需要财务总监特批，建议先确认再回复。"

**请求不符合规定**
> 按公司规定，住宿报销上限为一线城市每晚 600 元，超出部分暂无法报销。如因特殊情况需要超标准住宿，可以在出差前提交特殊申请。
> （"出差前提交特殊申请"必须是知识库里有的办法；没有就不写替代方案）

## 外部邮件的检查清单

发出前（交付时）检查草稿：
- [ ] 没有内部系统名（如"OA""TAP""XX 系统"）
- [ ] 没有内部价格、成本、折扣审批权限
- [ ] 没有其他客户的名称或信息
- [ ] 没有同事的手机号、个人信息
- [ ] 没有对价格、交期、赔偿的承诺（这些都应是【请确认】）
