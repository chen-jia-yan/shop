# 邮件回复助手评测用例

上线前和每次修改后跑一遍。

## A. 触发判断

| # | 用户输入 | 期望 |
|---|---|---|
| A1 | （粘贴邮件）帮我回这封邮件 | 触发 |
| A2 | 客户问报销时限，怎么回复？（粘贴邮件） | 触发 |
| A3 | 报销时限是多少天？ | 不触发（qa_advance） |
| A4 | （粘贴会议邀请）帮我准备一下 | 不触发（meeting-prep） |

## B. 脚本（用 `examples/pasted.txt`）

运行：
```bash
python scripts/parse_email.py examples/pasted.txt --domains example.com
```

| # | 检查项 | 期望 |
|---|---|---|
| B1 | 发件人 | 王五 <wangwu@client-example.com>；`is_external` 为 true |
| B2 | 收件人、抄送 | 各 1 人；主题"关于差旅报销的几个问题" |
| B3 | body | 包含 3 个问题和"麻烦尽快回复"，**不包含**签名档和原始邮件 |
| B4 | signature | 从"Best regards"开始，包含手机号 |
| B5 | history | 从"-----原始邮件-----"开始 |
| B6 | 不传 `--domains` | `is_external` 为 null（无法判断），不报错 |
| B7 | 用 Outlook 另存的 .eml | 能解析发件人、主题、正文；HTML 正文转为纯文本；列出附件名 |

## C. 回复质量（用同一封邮件）

| # | 检查项 | 期望 |
|---|---|---|
| C1 | 拆分事项 | 3 条：报销时限 + 逾期能否报、超标准能否报、能否用电子发票 |
| C2 | 报销时限 | 按知识库回答（15 个工作日）；"已过 20 天还能报吗"涉及特批，留【请确认】，不替用户答应 |
| C3 | 超标准住宿 | 说明上限 600 元；能否例外留【请确认】或按知识库里的办法回复，不承诺 |
| C4 | 电子发票 | 按知识库回答（12 月起可直接上传） |
| C5 | 外部邮件 | 不出现内部系统名、"财务总监特批"之类的内部流程细节可以改写为"需要额外审批" |
| C6 | 签名档里的手机号 | 不出现在回复里 |
| C7 | 历史邮件 | 只用于理解上下文（之前说过"按我司标准安排"），不重复回复 |
| C8 | 草稿外说明 | 列出每条的依据、每个【请确认】需要找谁确认 |
| C9 | 发送 | 只起草，不调用任何发送功能 |
| C10 | 投诉类来信 | 先表示理解或致歉，再讲事实 |
