# 知识生成 PPT

把知识库内容变成一套**能直接拿去讲**的演示文稿：结构清楚、每页一个重点、版式丰富、有演讲备注。

## 流程

### 1. 明确需求

用户已经说清楚的不要再问；缺的一次问完，最多 3 个问题。

| 信息 | 用途 | 用户没说时的默认值 |
|---|---|---|
| 主题 | 决定检索什么 | 必须明确 |
| 汇报对象 | 决定详略和措辞（领导/客户/同事/新人） | 领导 |
| 汇报类型 | 决定叙事结构，见 `reference/storylines.md` | 按描述判断 |
| 页数 | 控制内容量 | 10-12 页（不含封面和结束页） |
| 主题配色 | `business`（商务蓝）/ `tech`（科技青）/ `china`（中国红） | `business` |

### 2. 搭大纲

按 `reference/storylines.md` 选叙事结构，列出**每一页的标题和要讲的一个重点**。

- **标题写结论，不写话题**："报销时限缩短一半，结账提前 5 天" 优于 "报销时限调整"
- 每页只讲一件事
- 先确定每页用什么版式（见 `reference/slide-types.md`），避免连续 3 页以上用同一种版式

页数超过 8 页时，把大纲先给用户看一眼再继续（一句话一页，用户可以直接说"可以"）。

### 3. 按页检索

每页单独检索（Retrieval 链路为主，qa_advance 核实具体数字）。检索不到的内容填 `【待补充：缺什么】`，**不编造**数据和结论。

### 4. 写内容 JSON

格式见 `reference/slide-types.md`，保存为 `/tmp/kb_deck.json`。

内容密度规则（脚本会按这些规则检查并提示）：
- 要点页：每页不超过 6 条，每条不超过 40 字
- 数据卡片：2-4 个数字，每个数字配一句解释
- 时间线：3-6 个节点；流程：3-6 步
- 表格：不超过 6 行 × 5 列；更多的放进 Excel 附件（kb-to-excel）
- **每页都写 `notes`（演讲备注）**：这一页要讲的话，2-4 句，口语化

### 5. 生成 .pptx

```bash
python scripts/build_pptx.py /tmp/kb_deck.json /tmp/outputs/<文件名>.pptx
```

- 16:9 宽屏；字体为微软雅黑
- 每页自动加页眉标题、页码、页脚（单位名称 + 日期）
- 文字放不下时自动缩小字号（不低于下限），仍然放不下会输出警告
- 依赖：`python-pptx`（`pip install python-pptx`）

### 6. 自检

```bash
python scripts/check_pptx.py /tmp/outputs/<文件名>.pptx
```

检查：总页数、`【待补充】` 位置、缺演讲备注的页、文字过多的页。生成时有"文字放不下"的警告，先精简对应页的内容再重新生成。

### 7. 交付

告诉用户：
- 文件已生成，附下载
- 大纲（每页一行标题）
- `【待补充】` 的位置和缺的内容
- 用的哪套配色；想换配色，改一个参数即可重新生成

## 规则

- 不编造数据、结论、案例；没检索到就写 `【待补充】`。
- 对外（给客户）的演示稿：不出现内部系统名、内部价格、其他客户的信息。
- 图表数据必须来自知识库；数据不全时不画图，改用要点页或表格页，并标注缺什么。
- 文件名用中文主题加日期，比如 `XX项目进展汇报_20261116.pptx`。
