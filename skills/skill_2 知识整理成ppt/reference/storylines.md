# 叙事结构

按汇报类型选结构。页数是参考，可以增减；**每种结构的第一页内容页都是结论或要点**，不要从背景讲起。

## 工作汇报（给领导）

| # | 页 | 推荐版式 |
|---|---|---|
| 1 | 封面 | cover |
| 2 | 一页讲完：核心结论 3 条 | bullets 或 kpi |
| 3 | 关键数据 | kpi 或 chart |
| 4-6 | 分项进展（每项一页） | bullets / two_column / timeline |
| 7 | 问题与风险 | table 或 bullets |
| 8 | 需要领导支持/决策的事项 | quote 或 bullets |
| 9 | 下一步计划 | summary |
| 10 | 结束页 | end |

## 培训课件（给同事或新人）

| # | 页 | 推荐版式 |
|---|---|---|
| 1 | 封面 | cover |
| 2 | 学完能做什么（培训目标） | bullets |
| 3 | 目录 | agenda |
| 每个知识模块 | 章节页 → 概念讲解 → 操作步骤 → 注意事项 | section → bullets / two_column → process → bullets |
| 倒数第 3 | 常见错误 | table（错误 / 正确做法） |
| 倒数第 2 | 要点回顾 | summary |
| 最后 | 结束页（答疑） | end |
