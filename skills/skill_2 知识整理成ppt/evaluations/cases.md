# 知识生成 PPT 评测用例

上线前和每次修改后跑一遍。

## A. 触发判断

| # | 用户输入 | 期望 |
|---|---|---|
| A1 | 把 XX 项目做成汇报 PPT | 触发 |
| A2 | 做一份新人培训课件，讲报销流程 | 触发，叙事结构为"培训课件" |
| A3 | 写一份 XX 方案，Word 格式 | 不触发（kb-to-word） |
| A4 | 把产品参数整理成表 | 不触发（kb-to-excel） |

## B. 大纲与内容

| # | 场景 | 期望 |
|---|---|---|
| B1 | 任意汇报 | 第一页内容页是结论或要点，不从背景讲起 |
| B2 | 任意汇报 | 标题写结论（如"问答量 4 个月翻倍"），不写话题（如"问答量情况"） |
| B3 | 超过 8 页 | 先给用户看大纲再生成 |
| B4 | 任意汇报 | 没有连续 3 页以上使用同一版式（章节页除外） |
| B5 | 数据检索不到 | 填【待补充】；图表数据不全时不画图 |
| B6 | 对外演示稿 | 不出现内部系统名、内部价格 |
| B7 | 每一页 | 都有演讲备注（封面、结束页除外），口语化，2-4 句 |

## C. 脚本（用 `examples/sample_deck.json`）

运行：
```bash
python scripts/build_pptx.py examples/sample_deck.json out/test.pptx
python scripts/check_pptx.py out/test.pptx
python scripts/build_pptx.py examples/sample_deck.json out/test_tech.pptx --theme tech
python scripts/build_pptx.py examples/sample_deck.json out/test_china.pptx --theme china
```

| # | 检查项 | 期望 |
|---|---|---|
| C1 | 页数 | 14 页，13 种版式全部出现（section 出现 2 次） |
| C2 | 尺寸 | 16:9 宽屏 |
| C3 | 字体 | 中英文都是微软雅黑（在 PowerPoint 中选中文字查看） |
| C4 | 内容页 | 都有标题、标题左侧色块、分隔线、页脚（单位 + 日期）、页码、底部色条 |
| C5 | 封面 / 结束页 | 深色背景、装饰圆形；没有页码 |
| C6 | 章节页 | 自动编号 01、02 |
| C7 | 时间线 | 第 3 个节点高亮（橙色、更大），第 4 个节点为浅色 |
| C8 | 图表 | PowerPoint 原生柱状图，可以右键"编辑数据"；数据标签显示 1,200 等整数（无小数点）；右侧有"关键发现" |
| C9 | 表格 | 深色表头；"影响"列加粗着色 |
| C10 | 【待补充】 | 显示为橙色；check_pptx 列出 3 处所在页（图表页、表格页、总结页） |
| C11 | 三套主题 | 商务蓝 / 科技青 / 中国红，配色整体切换，版式不变 |
| C12 | 文字放不下 | 把某页要点改成 8 条长句后生成：字号自动缩小，并输出"可能放不下"和"超过 6 条"警告 |
| C13 | 图表数据不全 | 删掉 values 中一个数字后生成：不画图，显示【待补充：图表数据不完整】并警告 |
| C14 | 未知版式 | 写一个 `"type": "xxx"`：跳过该页并警告，不中断 |
