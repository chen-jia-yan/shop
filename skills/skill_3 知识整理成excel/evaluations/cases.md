# 知识整理成 Excel 评测用例

上线前和每次修改后跑一遍。

## A. 触发判断

| # | 用户输入 | 期望 |
|---|---|---|
| A1 | 把所有产品的参数和价格整理成一张对比表 | 触发 |
| A2 | 各城市的住宿报销标准列个表 | 触发 |
| A3 | 写一份产品介绍文档 | 不触发（kb-to-word） |
| A4 | 标准版多少钱？ | 不触发（qa_advance） |

## B. 结构确认

| # | 场景 | 期望 |
|---|---|---|
| B1 | 用户说清了对象和列 | 不追问，直接开始 |
| B2 | 用户只说"整理一下产品信息" | 先检索了解有哪些信息，提出不超过 8 列的建议，确认一次 |
| B3 | 对象清单 | 先检索确认一共有哪些对象，没有遗漏 |

## C. 内容质量

| # | 场景 | 期望 |
|---|---|---|
| C1 | 某个单元格知识库里没有 | 填【待补充】，不推测 |
| C2 | 两篇文档说法不一致 | 用新的，在备注里注明 |
| C3 | 数字类的列 | 单元格只有数字，单位在列名里 |
| C4 | 含价格的表 | 注明"内部资料，对外以正式报价单为准" |
| C5 | 交付 | 列出所有【待补充】的位置 |

## D. 脚本（用 `examples/sample.json`）

运行：
```bash
python scripts/build_xlsx.py examples/sample.json out/test.xlsx
python scripts/check_xlsx.py out/test.xlsx
```

| # | 检查项 | 期望 |
|---|---|---|
| D1 | 工作表 | 两个："版本对比"、"住宿报销标准" |
| D2 | 格式 | 标题行、深蓝底白字表头、边框、隔行底色；冻结表头；可筛选 |
| D3 | 数字列 | 价格右对齐、有千分位；折扣显示为 5%、10% |
| D4 | 日期列 | 显示为 2024-03-01 格式，Excel 中可按日期排序 |
| D5 | 【待补充】单元格 | 标黄；版本对比 2 个，住宿 1 个 |
| D6 | 中文列宽 | 中文内容不被截断，也不过宽（最宽 50） |
| D7 | check_xlsx 输出 | 版本对比 3 行 6 列、住宿 3 行 3 列；无空单元格（"—"不算空）；列出 3 处【待补充】 |
| D8 | 备注 | 显示在表格下方，不影响筛选范围 |
| D9 | 工作表名含 `/` 或超过 31 字 | 自动替换和截断，不报错 |
| D10 | 打印预览 | 列多时横向，宽度适配一页，每页重复表头 |
