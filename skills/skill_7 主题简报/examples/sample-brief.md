# 差旅报销

**一句话**：员工因公出差产生的住宿、交通等费用，按公司标准在出差结束后提交报销，经审批后由财务打款。

## 核心要点
1. **时限**：出差结束后 **15 个工作日内**提交，逾期需要额外审批
2. **住宿标准**：一线城市每晚不超过 600 元，二线城市 450 元，其他城市 350 元
3. **交通费**：按实际票据报销
4. **流程**：填报销单并附票据 → 部门负责人审批 → 财务审核 → 5 个工作日内打款
5. **电子发票**：12 月起可直接上传电子发票 PDF，不用打印

## 怎么办
1. **出差结束后**，在报销系统中填写报销单，上传全部票据
2. **部门负责人**在系统中审批
3. **财务部**审核票据和金额
4. 审核通过后 **5 个工作日内**打款到工资卡

| 项目 | 标准 |
|---|---|
| 住宿（一线城市） | 每晚 ≤ 600 元 |
| 住宿（二线城市） | 每晚 ≤ 450 元 |
| 住宿（其他城市） | 每晚 ≤ 350 元 |
| 交通 | 按实际票据 |

## 常见问题与易错点
- **超过住宿标准怎么办？** 知识库中暂未找到超标准报销的说明，建议提前向财务部确认。
- **时限按工作日计算**：2026 年 11 月起由"15 天"改为"15 个工作日"，节假日不计入。
- 注：《差旅费报销规定》2025 年版中时限为 15 天，已于 2026-11-12 调整。
