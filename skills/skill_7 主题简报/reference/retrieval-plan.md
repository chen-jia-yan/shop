# 检索计划

## 用哪个检索

| 用途 | 用哪个 |
|---|---|
| 按方面拉取多篇文档的原文片段 | **Retrieval 链路**（主力） |
| 核实某个具体事实（数字、时限、负责人） | **qa_advance** |
| 两个来源说法不一致，需要确认现行规定 | **qa_advance** |

## 检索词怎么写

每个方面用"主题 + 方面关键词"检索，必要时换说法再试：

| 方面 | 检索词示例（主题：差旅报销） |
|---|---|
| 适用范围 | 差旅报销 适用范围、差旅报销 适用人员 |
| 核心规则 | 差旅报销 标准、住宿标准、交通费标准、报销时限 |
| 办理流程 | 差旅报销 流程、报销 审批、报销 提交 |
| 材料表单 | 差旅报销 票据、报销单 |
| 例外情况 | 差旅报销 特殊情况、超标准 报销 |

## 检索次数

- 每个方面检索 1-2 次；第一次结果不相关时换一种说法，最多 3 次
- 总共控制在 15 次以内；主题范围大时，先只检索前 4 个方面，写完再判断是否需要补充
- 只保留和当前方面直接相关的片段，不要把所有结果都塞进上下文

## 新旧和冲突

- 同一方面有多篇文档时，看更新时间，以新的为准
- 新旧说法不一致：简报里用新的，并在对应位置注明"注：<旧文档名>中的说法为 XX，已于 <日期> 调整"；需要详细了解变化过程时，可以推荐 decision-trace
- 拿不准哪个是现行的：用 qa_advance 确认；仍然拿不准，两种说法都写出来，并建议用户向文档负责人确认

## 什么时候停下来问用户

- 主题检索不到任何内容（可能叫法不同，请用户提供别的叫法或相关文档名）
- 主题对应多个不同的对象（比如同名的两个系统），需要用户指定
