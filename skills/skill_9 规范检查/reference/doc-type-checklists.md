# 各类文档的检查重点

每类分两部分：
- **要检索的规范**：去知识库里找哪些规范作为依据。⚠️ 括号里是常见叫法，请按 TAP 里实际的规范名称替换。
- **检查项**：拿到规范后重点核对什么。**判定是否合规以检索到的公司规范为准**，这里只是提醒不要漏看。

---

## 合同

**要检索的规范**
- 合同模板（对应合同类型：采购、销售、服务、保密、框架协议……）
- 合同管理制度 / 合同审批制度
- 授权管理规定（签约权限、金额审批权限）
- 法务审核要点或常见风险条款清单（如有）

**检查项**
1. **主体信息**：双方名称、统一社会信用代码、地址、联系人是否完整，与模板要求一致
2. **必备条款**：对照模板，逐条核对模板要求的条款是否都有（标的、价款、付款、交付、验收、违约、争议解决、保密、知识产权、期限、生效……）
3. **被改动的模板条款**：和模板原文比，哪些条款被删除或改写，改写后是否对我方不利
4. **付款与金额**：付款节点、比例、方式是否符合制度；大小写金额是否一致；是否超出签约授权
5. **违约与责任**：违约金比例、责任上限是否符合规定；有没有对我方无限责任的条款
6. **争议解决**：管辖地、仲裁机构是否符合公司规定
7. **期限与续约**：起止日期、自动续约、解除条件
8. **签署信息**：签署页、盖章位置、日期是否完整

## 方案

**要检索的规范**
- 方案模板（对应方案类型：客户方案、技术方案、项目方案、投标方案……）
- 对外材料规范（品牌、措辞、保密要求、禁用表述）
- 报价与定价政策、折扣审批规定
- 相关产品或服务的现行说明（用于核对方案里的产品描述是否准确）

**检查项**
1. **结构完整**：对照模板，必备章节是否齐全
2. **产品和服务描述**：功能、参数、服务范围是否与知识库里的现行说明一致，有没有过时或夸大的描述
3. **承诺边界**：交付时间、服务等级、效果承诺是否超出公司规定可承诺的范围
4. **价格与商务条件**：报价、折扣、付款条件是否符合定价政策和审批权限
5. **对外信息安全**：是否包含内部系统名、内部价格、其他客户信息等不能对外的内容（对外方案）
6. **品牌与格式**：公司名称、Logo、产品名称写法是否规范

## 制度文件

**要检索的规范**
- 制度文件编写规范 / 公文格式规范
- 制度管理办法（制定、审批、发布流程）
- 与该制度相关的上位制度、现行同类制度（用于检查冲突）

**检查项**
1. **格式要素**：文件编号、版本号、生效日期、制定部门、审批信息是否齐全
2. **结构**：目的、适用范围、术语定义、职责、流程、附则等章节是否齐全（按公司编写规范）
3. **与现行制度冲突**：同一事项的规定是否和知识库里现行的其他制度矛盾（这是最重要的一项，矛盾的必须列为"必须修改"或"提示"）
4. **职责清晰**：每个流程步骤是否有明确的负责角色和时限
5. **引用有效**：引用的其他制度、表单是否存在且是现行版本
6. **表述规范**：强制性要求是否用"必须/不得/应当"等明确用语，避免"原则上""尽量"导致执行歧义

## 其他文档（报告、通知、说明、邮件稿等）

**要检索的规范**
- 公文/文档格式规范
- 对外发布或对内通知的相关规定
- 文档中涉及的业务事项对应的现行规定

**检查项**
1. **格式**：是否符合公司文档格式规范（标题、落款、日期等）
2. **事实准确**：文中涉及的政策、流程、数据是否与知识库现行内容一致
3. **信息安全**：是否包含不应出现的敏感或内部信息
4. **表述**：是否有与公司规定不符的承诺或说法

---

## 判断不了文档类型时

按"其他文档"检查，并在交付时说明："如果这是 XX 类文档，告诉我，我按对应规范再查一遍。"
