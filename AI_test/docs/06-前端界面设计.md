## 1. 整体布局

### 1.1 导航结构

采用 Power Apps 模型驱动应用的标准三栏布局：

```
┌─────────────────────────────────────────────────────────┐
│ 顶部工具栏：应用名称 | 全局搜索 | AI Copilot 开关 | 用户头像 │
├──────────┬──────────────────────────────────────────────┤
│          │                                              │
│ 左侧导航  │              主内容区域                       │
│ (折叠式)  │                                              │
│          │   ┌──────────────────────────────────────┐   │
│ ├ 仪表盘  │   │  页面标题       [操作按钮组]          │   │
│ ├ 项目管理 │   │──────────────────────────────────────│   │
│ ├ 需求管理 │   │                                      │   │
│ ├ 用例管理 │   │       页面主要内容区域                 │   │
│ ├ 用例评审 │   │                                      │   │
│ ├ 脚本管理 │   │                                      │   │
│ ├ 测试执行 │   │                                      │   │
│ ├ 结果分析 │   │                                      │   │
│ └ 报告中心 │   └──────────────────────────────────────┘   │
│          │                                              │
├──────────┴──────────────────────────────────────────────┤
│ 底部状态栏：连接状态 | 最后刷新时间 | AI 服务状态          │
└─────────────────────────────────────────────────────────┘
```

**导航项定义：**

| 图标 | 名称 | 可见范围 | 说明 |
|------|------|----------|------|
| 🏠 | 仪表盘 | 所有用户 | 项目概览首页 |
| 📁 | 项目管理 | 管理员/项目经理 | 项目增删改查 |
| 📄 | 需求管理 | 所有用户 | 需求文档上传与解析 |
| 📋 | 用例管理 | 所有用户 | 测试用例维护 |
| ✅ | 用例评审 | 测试组长/评审人 | 用例审批流程 |
| ⚙️ | 脚本管理 | 测试工程师 | 自动化脚本生成与跟踪 |
| ▶️ | 测试执行 | 所有用户 | 执行计划与实时监控 |
| 📊 | 结果分析 | 所有用户 | 测试结果与AI分析 |
| 📑 | 报告中心 | 所有用户 | 报告生成与导出 |

**导航规则：**
- 左侧导航宽度 200px（折叠后 60px），使用 Power Apps `SiteMap` 定义
- 当前活跃页面高亮显示
- 根据用户角色动态显示/隐藏菜单项
- 移动端自动折叠为底部 Tab Bar

### 1.2 顶部工具栏

```
┌──────────────────────────────────────────────────────────────┐
│ 🔍 [全局搜索框]     [AI Copilot 💬]    [🔔 通知]    [👤 张三] │
└──────────────────────────────────────────────────────────────┘
```

- **全局搜索**：跨项目/需求/用例模糊搜索，使用 Power Apps `Search` 控件
- **AI Copilot 开关**：切换右侧 AI 助手面板显隐
- **通知**：待评审数、执行完成提醒、AI 解析完成通知
- **用户头像**：个人设置、登出、主题切换

### 1.3 响应式设计策略

| 断点 | 宽度 | 布局策略 |
|------|------|----------|
| Desktop | ≥ 1200px | 三栏完整布局 |
| Tablet | 768px ~ 1199px | 左侧导航自动折叠为图标 |
| Mobile | < 768px | 全屏单栏，导航转为底部 Tab |

**具体措施：**
- 使用 Power Apps `Responsive` 布局容器
- 表格组件在小屏自动切换为"卡片列表"视图
- 弹窗在大屏用侧面板（Panel），小屏用全屏对话框
- 图表组件在移动端折叠为摘要数字

#### 3.3.2 组件列表

#### 3.3.4 交互逻辑

1. **上传文档** → 选择文件 → 上传至 SharePoint / Dataverse File → 触发 Power Automate Flow → Flow 调用 Azure OpenAI → 异步解析 → Webhook 回写 `ag_RequirementAIParse`
2. **解析状态轮询**：上传后前端每 10 秒轮询 `ag_Requirement.Status`，显示进度动画
3. **解析完成**：自动刷新右面板，显示 AI 解析摘要和模块列表
4. **同步到用例**：将选中的模块批量创建为 `ag_TestCase` 记录
5. **版本对比**：选择两个版本 → 高亮显示差异模块

## 附录

### A. 界面设计原则

1. **不超过 3 次点击**：任何常用操作应在 3 次点击内完成
2. **错误优先**：失败/异常信息使用红色高亮，排在列表前列
3. **AI 透明**：AI 生成的内容必须标注，并允许用户修改/拒绝
4. **渐进式加载**：大数据量表优先显示前 20 条，滚动或翻页时追加
5. **一致性**：相同类型的操作在页面间保持位置和样式一致
6. **实时反馈**：耗时操作（超过 3 秒）必须显示进度状态

### B. Power Apps 控件映射

| 需求场景 | Power Apps 控件 |
|----------|----------------|
| 数据列表 | `Gallery` + `VerticalGallery` / `HorizontalGallery` |
| 编辑表单 | `EditForm` + `DisplayForm` |
| 筛选搜索 | `TextSearchBox` + `ComboBox` / `Dropdown` |
| 图表 | `Charts` (Line, Bar, Ring) |
| 导航 | `Navigation` / `NavigationItem` |
| 文件上传 | `AddMediaControl` / `Launch(Upload)` |
| 对话框 | `Dialog` / `SidePanel` |
| 流程图 | `Power Automate for desktop` / 自定义 Canvas |

### C. 性能目标

| 指标 | 目标 |
|------|------|
| 页面初始加载 | < 3 秒 |
| 列表滚动 | 60 fps 无卡顿 |
| AI 请求响应 | < 10 秒（含 Azure OpenAI 调用） |
| 实时日志延迟 | < 3 秒（从执行完成到前端显示） |
| 数据刷新 | 手动刷新 < 2 秒 |
