### 执行监控页面功能列表

| 功能 | 说明 |
|------|------|
| 实时进度 | WebSocket 推送，每完成一个用例自动更新 |
| 用例状态列表 | 颜色编码状态 + 执行耗时 |
| 日志面板 | 滚动的实时日志，支持搜索和过滤 |
| 截图查看 | 点击失败用例可查看执行截图 |
| 暂停/终止 | 控制执行任务的生命周期 |
| 执行器状态 | 显示执行器池健康状态和负载 |
| 导出 | 导出当前执行日志 |

### 状态颜色编码

| 颜色 | 状态 | 含义 |
|------|------|------|
| 🟢 绿色 | PASSED | 测试通过 |
| 🔴 红色 | FAILED | 测试失败 |
| 🟡 黄色 | RUNNING | 执行中 |
| ⚪ 灰色 | PENDING | 等待执行 |
| ⭕ 黑色 | BLOCKED | 阻塞/超时 |
| ⏭️ 蓝色 | SKIPPED | 跳过 |
