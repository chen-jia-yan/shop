# 任务:chunk 可视化工作台 UI 企业级重做(前端重写,后端契约冻结)

## 目标
把现有 chunk-studio 页面从"工具感/圆角方块堆叠"重做成**保险行业企业级** UI:数据表格 + 主从布局 + 按需展开(progressive disclosure)+ 克制配色。**这是前端展示层的重写,不是在现有页面上微调**;但后端接口与数据结构必须一字不动。

## 参考(先看后抄,抄规范不抄框架)
- Ant Design Pro(企业级数据密集标杆):https://preview.pro.ant.design
- Ant Design 组件(表格 Table、抽屉 Drawer、标签页 Tabs、描述列表 Descriptions 的用法与观感):https://ant.design/components/overview
先打开看,用几句话说清"要借鉴它的哪些布局/组件规范",再动手。**不要引入 React/antd 或任何新框架**,用项目现有的前端技术栈(vanilla HTML/CSS/JS)重写,只借鉴它的视觉规范和交互模式。

## 第 0 步(动手前必须做):冻结数据契约
先梳理并**原样列出**当前 chunk-studio 前端调用的所有后端接口:每个接口的 URL、请求参数、以及**返回的 JSON 字段结构**。输出成一份"数据契约"清单给我确认。这是后续不能改的锚点。

## 三条铁律(必须遵守)
1. **只重写前端**(chunk-studio 的 HTML/CSS/JS/模板)。**不改后端路由、不改产数据的 service、不改任何现有接口的名字/参数/返回字段。**
2. 新 UI **消费的还是同样的接口、同样的数据**。
3. 若新 UI 确实需要后端目前没提供的数据:**只允许新增**(新接口或新的可选字段),**禁止修改/删除/重命名**现有接口与字段。

## 布局与交互(企业级,按需展开)
- **顶栏**:精炼小标题 + 全局操作(刷新等),细、专业,不占大块。
- **左侧:文件列表 = 数据表格**(列:文件名 / 类型 / chunks 数 / 大小),可排序、可搜索/过滤;**不要用大圆角卡片块**。
- **主从布局**:在左侧选中一个文件 → 右侧显示该文件详情。
- **详情区用标签页(Tabs)分开**:结构树 / 调参 / chunk 列表 / 中间产物,**一次只显示一个,不要全部堆叠**。
- **按需展开(progressive disclosure)**:
  - **中间产物(OCR 图 / JSON / 结构化 artifact)**:点击某个 chunk 时,从**右侧抽屉(Drawer)/侧面板**划出显示,不常驻。
  - **草稿编辑**:只有进入"编辑模式"时才出现拆分/合并/拖边界的控件。
  - **调参**:收进"调参"标签页或可折叠"高级"区,需要时展开。
  - 点击单个 chunk → 详情面板显示其 token 数、来源(title_path/block_type)、artifact 溯源。

## 视觉规范(杀掉幼稚感)
- 卡片:**方正、1px 细边框或极浅阴影、小圆角 4–6px**;用**分隔线和留白**建立层级,不用大圆角气泡块。
- 字体:整体调小加密,分三档层级(标题 / 正文 / 元数据);chunk 正文与 JSON 用**等宽字体**;中日文用合适行高。
- 配色(中性底 + 单一橙强调):
  - 背景 `#FFFFFF` / 米白 `#FAF9F6`;次级面板米色 `#F5F1EA`;边框暖灰 `#E7E2D9`。
  - 主强调 沉稳橙 `#E8631A`(非荧光),**只用于主按钮、选中态、关键高亮**,克制使用。
  - 文本 `#1F2328`,次级 `#6B7280`。
  - **切片质量用语义色:干净=绿 `#2FB344`、半截=琥珀 `#E8A400`、硬切=红 `#D64545`,与橙色分开,不混用。**

## 明确不做
- 不改后端、不改数据契约、不引入新框架、不动主链路/worker/索引。
- 不为了"省事"把已有功能(结构树、调参预览、草稿编辑、中间产物)删掉——功能全保留,只是重新组织成按需展开。

## 验收标准
- 对照"冻结契约":所有现有接口的 URL/参数/返回字段**完全没变**;新 UI 只消费这些(+ 任何新增的可选项)。
- 页面观感:数据表格 + 主从 + 标签页 + 抽屉;圆角方块气泡消失;橙/白/米色克制配色;字体分层清晰。
- 中间产物、草稿编辑、调参都改成**点击/展开才出现**,不再一屏堆满。
- 原有功能一个不少。

## 验证方式
