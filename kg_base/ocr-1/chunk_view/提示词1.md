# 提示词 1/4:独立模块骨架 + 只读可视化(含中间产物完整展示)

## 目标
搭起独立的 chunk 可视化工作台,先做**只读展示**:结构化分层看 chunk,并**完整展示中间产物**(OCR 图 / 结构化 artifact 本身,不只是链接)。

## 参考(先看后抄)
- RAGFlow https://github.com/infiniflow/ragflow — 抄 chunk 卡片分层展示的客户向 UX。
- RAG-TUI https://github.com/rasinmuhammed/rag-tui — 抄 🟢🟡🔴 切片质量标记。
先打开看、各用两三句说清借鉴点,再动手;抄模式不抄代码,尊重开源许可。

## 范围(严格隔离)
- 新建独立模块 `kb_chunk_studio/`(自己的接口 + service + 前端页面/tab)。
- **不改主 UI、不改 worker/索引/切片核心。** 只做只读:读 chunk JSON、读 `artifact_path` 指向的文件。

## 功能
- 文件列表 → 选一个文件(为后续批次浏览留位)。
- 左:结构树(slide/sheet → block);右:chunk 卡片。
- 卡片:🟢🟡🔴 标切得好不好 + 每块 token 数(暴露超长块)+ 点击溯源 `title_path/block_type`。
- **中间产物完整展示**:点 chunk 能看到它对应的 OCR 图 / 结构化 artifact **本身**(渲染出来,不只给路径)。

## 保持不变
纯读,不写任何文件、不碰主链路。全离线。

## 验收
- 独立模块,删掉不影响主流程。
- 能看结构树 + chunk 卡片(颜色 + token)+ 直接看到中间产物内容。

## 验证方式
静态 + 单文件小测,不要跑整个 worker。
