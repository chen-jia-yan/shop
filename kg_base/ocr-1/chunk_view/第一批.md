任务目标:给 chunk_studio 做三处"安全快修",只加健壮性,不改功能、不改接口。

范围(只允许动这两个文件):
- chunk_studio/api.py
- chunk_studio/segment_cache.py

明确不做(红线):
- 不碰切片/解析/OCR/索引等任何核心逻辑;
- 不改任何接口的路径、参数名、返回字段结构(前端在用,只能加不能改);
- 不"顺便"重构无关代码。

具体改动:
1. api.py — handle_post 里 /api/chunk-studio/draft/create:
   现在是 `file_id = int(payload.get("file_id") or 0)`,传非数字会抛 ValueError 导致 500。
   改成:先取原始值,校验是数字再转 int;不是数字就返回 400 JSON(`{"error":"file_id is required"}`),照抄本文件 GET 接口里 isdigit() 的那套写法,保持风格一致。

2. api.py — 给这三个目前"裸奔"的分支补上和其他接口一致的错误处理:
   - GET /api/chunk-studio/files
   - GET /api/chunk-studio/drafts
   - POST /api/chunk-studio/draft/save
   用和同文件其他分支一样的 try/except:捕获 FileNotFoundError → 404、ValueError → 400,其余异常 → 500 JSON。成功路径的返回保持原样不变。

3. segment_cache.py — load_document_snapshot:
   现在缓存文件损坏/写了一半时 `json.loads` 会抛异常、让 preview 整个崩。
   改成:读取和解析用 try/except 包住,出错就当缓存没命中、返回 None(让上层重新解析),不要抛异常。

必须保持不变:
- 所有成功响应的 JSON 字段和结构;
- 缓存命中/未命中的正常逻辑;
- 其余文件一律不动。

验收标准:
- draft/create 传非数字 file_id 返回 400 而不是 500;
- /files、/drafts、/draft/save 内部出错时返回规范 JSON 错误,不再吐堆栈;
- 删掉或写坏一个 cache 的 .segments.json 后,preview 能自动重解析、不报错。

验证方式:
- py_compile / import 静态检查;
- 单接口小测,别真跑整个 worker。

风险与回退:都是加校验/加 try,纯防御;改坏了把对应函数还原即可。
