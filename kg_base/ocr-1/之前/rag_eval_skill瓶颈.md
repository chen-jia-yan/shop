## 四、已确认的瓶颈（全部有实证）
1. **评估基建曾严重失真（已修）**：评估曾绕过查询扩展、把未重写的中间素材当"答案"打分、passed_count 因运算符优先级 bug 显示"全部通过"。三轮修复后评估结果才可信。
2. **向量召回曾被门禁团灭（已修）**：向量候选 term_coverage 恒为0 → 必被拒。修复后 #01/#28 首次出现纯向量命中通过门禁。
3. **覆盖率算法误杀（已修）**：长复合词整词子串匹配，"代理店手数料"被表格拆开就记0 → 正确文档 cov=0.01。修复后8条空检索恢复7条。
4. **【剩余】命中率天花板 ≈2.5 = Azure `standard.lucene` 分析器**：日文按单字切，粗筛 top‑40 候选质量差（实证：Q1 期望文档11个含"PPL"的chunk无一候选选）。只能靠换 `ja.lucene` + 建新索引。
5. **【剩余】完整性天花板 ≈1.8 = 语料粒度/质量**：画面要件定義書类文档的 chunk 是截图 OCR 噪声（带坐标、有错字）；#25期望文档291 chunks中标题关键词"任意再保険"出现0次。列举型答案散落在多 sheet，top‑8 也拼不全。
6. **【已证伪】阈值重标定无效**：放宽到0.10结果逐条零变化—问题在算法不在阈值。
