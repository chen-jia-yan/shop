五、规则分类 classify(item) -> str | None（core/library_eval/analyzer.py）
按下面的顺序判断，命中第一条就返回：
1. item.status == "error" → None
2. item.parse_error 为 True，或 scores 为空 → "judge_parse_error"
3. correctness 分数 ≥ 3 → "ok"
4. evidence 中 kind == "chunk" 的条目为 0 条 → "empty_retrieval"
5. expected_source 非空，且所有 chunk 证据的 source_file 都不匹配 → "retrieval_miss"
   匹配规则：取 expected_source 中第一个 " / " 之前的部分作为文件名，与 source_file 比较时两边都去掉首尾空白、转小写，完全相等才算匹配
6. completeness 分数 ≤ 2 → "context_fragment"
7. faithfulness 分数 ≤ 2 → "generation_issue"
8. 其他 → "other"
返回值只能是：None、"judge_parse_error"、"ok"、"empty_retrieval"、"retrieval_miss"、"context_fragment"、"generation_issue"、"other"
SUGGESTIONS 的键是除 ok 以外的 6 个类别，文字逐字使用：
- judge_parse_error：检查判官模型的输出格式，必要时重跑该题
- empty_retrieval：检查该问题能否检索到切片，确认相关文档已入库、检索参数是否过严
- retrieval_miss：检索到了切片但不是期望的文件，检查查询改写、关键词和向量召回
- context_fragment：找到了正确的文件但内容不全，考虑命中后回填相邻内容或调整切片粒度
- generation_issue：答案包含证据不支持的内容，检查生成提示词和推断证据的使用
- other：需要人工查看
"表格碎片 / 漏召回 / 编造 / 幻觉 / 多模态遗漏 / 切片截断 / 检索方向错误 / 未分类"不得出现在 classify、SUGGESTIONS 和统计逻辑中。
