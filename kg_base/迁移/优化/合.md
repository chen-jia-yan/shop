可能会问 你可以这样回答

接口现在能调吗？ 代码写好了。开发环境建好表、打开开关以后，评估集和草稿这部分就能联调。问答、读切片、落库要等第二期接上同事的代码，在那之前会返回"xxx 未配置"。你们可以先按文档用假数据写页面
为什么出错了状态码还是 200？ 这是整个后端统一的规范，同事的接口也是这样。判断成功还是失败要看 code 字段
评估要跑多久？进度怎么拿？ 评估在后台跑，一道题大概几秒到几十秒。前端每 3 秒查一次任务详情，用 done / total 算进度，状态变成结束状态以后就停止查询
评估能中途停吗？ 能，调"取消"接口。正在跑的那道题会跑完，剩下的不再跑，最后状态是 cancelled
后台服务重启了，评估会怎么样？ 后端启动时会自动检查，超过 10 分钟没有心跳的任务会标记为 interrupted。需要的话重新发起评估就行
评估结果怎么看？ 结果列表可以按类别筛选，比如 retrieval_miss（找错了文件）。点一道题看详情，能看到答案、用到的证据、4 个维度的评分和理由。分析接口返回各个类别的数量、例题和改进建议
评估集用什么格式导入？ 现在的接口收 JSON：一个名称，加一个题目数组，每道题有问题、标准答案、期望来源、要点。Excel 由谁来转换，会上一起定
切片可以直接改吗？ 不能直接改。要先创建一份"草稿"，在草稿里修改、新增、删除，保存后再"提交落库"，这时才会替换索引里这个文件的切片
编辑的时候文件被重新入库了怎么办？ 提交时后端会检查。如果文件已经被重新入库，会返回"文件已重新入库，请重新创建草稿"
落库以后，知识图谱会同步吗？ 不会自动同步，这是同事那边的模块。另外要提醒一下：这个文件以后如果重新入库，手动改过的内容会被覆盖
有没有接口文档页面？ 后端有自动生成的接口文档页面（/docs）。不过以我们这份文档为准，里面多了状态说明和流程
字段以后还会变吗？ 字段名不会再变。如果有变化，我会提前通知
