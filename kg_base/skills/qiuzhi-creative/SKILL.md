# 秋芝餐厅物料创意生成器

为秋芝餐厅生成符合品牌调性的营销物料创意方案和图片。

## 品牌核心

- **品牌**: 秋芝餐厅 — 年轻、潮流、有网感、健康轻食主义
- **IP**: 3D 薄荷绿卡通葫芦（大眼睛、微笑、白色条纹）
- **主色**: `#5DDEB5` 薄荷绿 + 白色
- **Slogan**: A FRESH, MODERN BITE / 健康轻食主义
- **风格**: 3D 卡通与实拍结合，杂志感排版，高饱和度

品牌完整规范见 `references/brand-specs.md`。

## 物料类型路由

| 类型 | 涵盖物料 | 规格文档 |
|------|---------|---------|
| **常规物料** | 海报、插图、横幅 | 直接用下方内置规格 |
| **实体物料** | 杯子、工服、餐盒、菜单、易拉宝 | 读取 `references/physical-specs.md` |
| **社交媒体** | 小红书、公众号、微博 | 读取 `references/social-specs.md` |

### 常规物料内置规格

- **海报**: 720×1280，3D 吉祥物 + 艺术大标题，中英文混排，标题占比约 1/4
- **网站横幅**: 1280×720，左右分栏或居中构图，预留文字留白
- **活动插图**: 1024×1024，3D 与平面结合，上下左右留边保持呼吸感

## 工作流

### 步骤 1: 输出创意方案

按 `references/creative-template.md` 四段式格式输出：

```
### 创意主题
(一句话概括)

### 视觉风格
(氛围、配色、质感)

### 画面构成
(标题区 + 主体区 + 信息区 + 品牌区 + 装饰)

### 细节建议
(3-5 个出彩细节)
```

### 步骤 2: 询问是否生图

使用 `AskUserQuestion` 询问用户是否需要生成图片：
- 是 → 询问输出路径（默认 `./output`）→ 执行步骤 3
- 否 → 结束

### 步骤 3: 调用生图脚本

```bash
python <skill-path>/scripts/generate_image.py \
  "<需求描述>" \
  -t <物料类型> \
  -o <输出路径> \
  -r <skill-path>/assets/logo.png \
  -n <张数>
```

**物料类型参数** (`-t`): `poster` | `hat` | `tshirt` | `apron` | `menu` | `social` | `coupon` | `box` | `banner`

**张数** (`-n`): 默认 1，最多 4

**脚本说明**:
- 自动拼装品牌提示词（含 IP 形象、配色、风格要求）
- 自动以 `assets/logo.png` 作为参考图传入 API
- 使用硅基流动 `tongyi-mai/z-image-turbo` 模型
- 同步返回，无需轮询等待

### 步骤 4: 展示结果

生成完成后，用 `Read` 工具展示生成的图片文件。
