# 秋芝餐厅 — 实体物料规格参考手册

---

### 1. 品牌纸杯 / 冷饮杯

杯子是离顾客最近的触点，强调辨识度与拍照传播力。

| 参数项目 | 规格标准 |
|---|---|
| **杯型建议** | 热饮：中空隔热白卡纸杯（360ml / 500ml）；冷饮：磨砂透明 PET 杯（500ml / 700ml） |
| **颜色应用** | 以纯白或薄荷绿渐变为主，内壁保留本色 |
| **设计布局** | 杯身正面居中为吉祥物头像 + 品牌名，背面为大号英文 Slogan "A FRESH, MODERN BITE" |
| **细节装饰** | 杯口下方环绕一圈薄荷绿细条纹，底部点缀白色葫芦暗纹 |
| **防烫杯套** | 牛皮纸色，印吉祥物表情包 + 小字 "小心烫，但好喝" |
| **吸管/杯盖** | 吸管套上印薄荷绿 Logo 图形；杯盖贴纸为圆形吉祥物表情贴（直径 3cm） |

---

### 2. 品牌工服

工服是移动的品牌名片，强调简约与亲和力。

#### A. T 恤 / Polo 衫
- **颜色**：主推【薄荷绿】或【纯白】
- **Logo 位置**：
  - 左胸：简约图形 Logo（3-4cm）
  - 背部居中：3D 吉祥物或大 Slogan（15-20cm）
- **材质**：高支棉或排汗速干面料（考虑到厨房/服务环境）

#### B. 棒球帽
- **颜色**：薄荷绿配白绣 / 黑色配薄荷绿
- **设计**：正面绣吉祥物头像，侧面或背面绣英文 Slogan "FRESH BITE"

#### C. 围裙
- **颜色**：深灰色或薄荷绿
- **设计**：胸前印制白色/薄荷绿大 Logo，口袋边缘使用薄荷绿色边

---

### 3. 外卖餐盒

体现"健康轻食主义"的环保心智。

| 参数项目 | 规格标准 |
|---|---|
| **材质建议** | 植物纤维纸浆盒 / 加厚白卡纸（可降解） |
| **颜色应用** | 建议以牛皮纸原色或白色为基底，局部印刷薄荷绿 |
| **设计布局** | 盖面中心为"圆形 Logo + 吉祥物"，侧面环绕印刷 Slogan |
| **封口贴** | 圆形薄荷绿贴纸（直径 4cm），印吉祥物表情包 |

---

### 4. 品牌菜单

菜单是点餐决策的核心载体，兼顾信息清晰度与品牌调性。

| 参数项目 | 规格标准 |
|---|---|
| **材质建议** | 封面：厚牛皮卡纸 + 薄荷绿烫印；内页：微涂哑光纸（防水防油） |
| **颜色应用** | 封面薄荷绿为主，内页以奶油白底 + 薄荷绿标题栏分隔 |
| **设计布局** | 封面：居中 Logo + 吉祥物 + Slogan；内页：菜品名左对齐、价格右对齐，中间虚线连接 |
| **字体规范** | 品名用圆体/无衬线字体体现年轻感，价格用加粗同色系 |
| **特色板块** | 设置"主厨推荐""轻食必点"分区，用薄荷绿底反白字标注 |
| **附加细节** | 每道招牌菜旁点缀迷你葫芦图标；菜单折页边缘印上网感文案，如"选好了吗？葫芦都饿了" |
