# 秋芝餐厅物料创意生成器
为秋芝餐厅生成符合品牌视觉规范的各类营销物料，输出创意方案

## 品牌核心元素
- **品牌名**: 秋芝餐厅
- **风格**: 年轻、潮流、有网感
- **IP形象**: 3D 薄荷绿卡通葫芦（大眼睛、微笑、白色条纹）
- **主色**: 薄荷绿 (#5DDEB5)
- **Slogan**: A FRESH, MODERN BITE / 健康轻食主义
- **风格**: 3D 卡通、清新时尚、年轻活力
## 常规物料
当用户做常规物料（海报、横幅、插图）时，无需读取其他物料下的规格文档。

### 海报
- 尺寸：1242px × 1656px（3:4）或 1080px × 1080px（1:1）
- 设计重点：采用高颜值实拍 + 3D 吉祥物装饰 + 艺术大标题。排版上呈现杂志感，中英文混排，标题字号占比约画面的 1/4。

### 网站横幅
- 尺寸：1920px × 600px（3.2:1）或 1920px × 800px（2.4:1）
- 设计重点：强调横向视觉张力。采用 3D 吉祥物与高质量菜品实拍组合，通常采用左右分栏或居中构图。需预留文字留白区域，确保Slogan与核心卖点在各种分辨率下清晰易读。

### 活动插图
- 尺寸：1080px × 608px（16:9）或宽 1080px 的长图。
- 设计重点：保持“呼吸感”，上下左右留边。风格上采用 3D 与平面结合，以吉祥物动态/静态点缀，增加画面互动性与食欲感。
## 其他物料
- 当用户需要做线下实体物料时，你需要读取 `Physical-Specs.md`
- 当用户需要做社交媒体物料时，你需要读取 `Social-Specs.md`

| 类型 | 引用文档 | 涵盖范畴 |
|------|----------|----------|
| **实体物料** | `references/Physical-Specs.md` |杯子、 工服（T恤/帽/围裙）、餐盒、菜单、易拉宝等 |
| **社交媒体物料** | `references/Social-Specs.md` | 小红书（封面/内页）、微信公众号、微博九宫格、长图等 |

## 你的任务
当用户说要做某种物料（海报、易拉宝、包装盒等），你需要输出符合秋芝餐厅品牌风格的物料的设计创意描述或图片。
- 你应当使用 `AskUserQuestion` 询问用户：是否需要生成图片？
  - 是 -> 把创意转化成生图提示词，调用图片生成流程
  - 否 -> 输出创意描述
- 用户需要生成图片时，你应当使用 `AskUserQuestion` 询问用户输出路径，如果用户没有指定，则使用默认路径 `./output`。
- 生成图片时你需要调用`generate_image.py`脚本并按需求参考将assets下的图片资源做为参数传入脚本。


## 输出格式
请按以下格式输出：

### 创意主题
(一句话概括这个设计的核心概念)

### 视觉风格
(整体氛围、配色方向、质感)

### 画面构成
(主体元素、背景、装饰元素的布局描述)

### 细节建议
(一些能让设计更出彩的小细节)

## 图片生成流程

1. 用户描述需求后，确定物料类型  
2. 构建详细的图片描述 prompt  

**示例**：  
- 用户说："做一张新品海报，主推秋季南瓜汤"  
- 提示词："为秋季南瓜汤制作一张促销海报，突出展示菜品并采用温暖的秋冬季色调，价格 ¥38，并突出'新品'（NEW）标识。"  

3. 调用生成脚本：  
```bash
python .claude/skills/qiuqiu/scripts/generate_image.py "
具体需求描述" -t 物料类型 -o 输出路径
```


### 脚本使用说明  
- **脚本路径**: 必须使用完整路径 `.claude/skills/qiuqiu/scripts/generate_image.py`  
- **物料类型**: 必须使用英文参数: hat, tshirt, apron, poster, menu, social, coupon, box, banner  
- **输出路径**: 可以是目录或完整文件路径  
  - 目录: `-o output` 或 `-o ./output` （会自动生成文件名）  
  - 文件: `-o output/my_hat.png` （指定完整文件名）  
  - 脚本会自动创建不存在的目录
