请帮我在当前 Python 项目里彻底解决"缩进/换行/编码反复出错"的问题。背景：我在 Windows 上开发，用多个工具（手写 + AI 生成）往同一批文件写代码，经常出现缩进不一致、tab 和空格混用、CRLF/LF 混乱、UTF-8 编码问题，改来改去越改越乱。我要的是**自动化根治**，不是手动修。请按以下步骤实现，并在每步告诉我做了什么：

1. 在项目根目录创建 `.editorconfig`，统一所有编辑器的行为：
   - 全局：charset = utf-8、end_of_line = lf、insert_final_newline = true、trim_trailing_whitespace = true
   - `*.py`：indent_style = space、indent_size = 4
   - `*.{html,js,json,jsonl,yml,yaml}`：indent_style = space、indent_size = 2

2. 在项目根目录创建 `.gitattributes`，统一换行符：
   - `* text=auto eol=lf`
   - `*.py text eol=lf`，`*.html text eol=lf`，`*.jsonl text eol=lf`，`*.md text eol=lf`
   - 二进制文件（png/jpg/pdf/ico）标记为 binary

3. 引入 Ruff 作为统一的格式化 + 代码检查工具（它能自动修复缩进、tab/空格混用、尾部空格等）：
   - 把 ruff 加进项目依赖（pyproject.toml 或 requirements-dev.txt）
   - 在 pyproject.toml 里配置 ruff：line-length、target-version，并启用 format 和 lint
   - 用 `ruff format .` 和 `ruff check --fix .` 把现有所有 .py 文件一次性格式化干净

4. 配置 pre-commit，让每次 git commit 自动跑格式化，从源头杜绝乱缩进进仓库：
   - 创建 `.pre-commit-config.yaml`，加入 ruff（format + lint）以及 end-of-file-fixer、trailing-whitespace、mixed-line-ending 这几个 hook
   - 给出安装和启用命令（pip install pre-commit && pre-commit install）

5. 一次性规范化已有文件的换行符：执行 `git add --renormalize .`，并把本地 Git 设为 `core.autocrlf=input`。

6. 创建或更新一个 VS Code 配置 `.vscode/settings.json`：设置 `files.eol = "\n"`、`files.encoding = "utf8"`、`editor.insertSpaces = true`、`editor.tabSize = 4`、`editor.formatOnSave = true`，并把 ruff 设为默认 Python 格式化工具。

完成后，请总结我今后需要记住的 1~2 条规则，并确认：以后无论谁（包括 AI）写出什么样的缩进，保存和提交时都会被自动修正成统一格式。
