# 任务:占锁进程已死时,启动 worker 自动清旧锁

## 目标
现在硬杀 worker 后重启,还得手动 `Remove-Item worker.pid.lock` 才能起来,说明"占锁 PID 已死就自动清锁"没生效。修好它:启动时若锁文件里记录的 PID 已经不存在,就自动删掉旧锁并正常启动。

## 先说明再动手
先看 `kb_admin/worker.py` 的 `_acquire_worker_lock()`,说清现在为什么没自动清、要怎么改。

## 具体改动
- 读到已有锁时,检查锁里记录的 PID 是否还活着:
  - **已死** → 删掉旧锁,继续正常获取锁并启动。
  - **还活着** → 才报"lock is held"错误(保持现有保护)。

## 保持不变
- 两个 worker 真同时跑时,第二个仍必须被正确挡住(单实例保护不能削弱)。

## 验收标准
- 硬杀 worker 后直接 `python -m kb_admin.worker`,**不用手删锁**也能起来。
- 手动起第二个 worker(第一个还活着)时,第二个仍被正确拒绝。
