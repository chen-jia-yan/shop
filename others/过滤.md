# 任务:文件入队前过滤掉垃圾/临时/非文档文件

## 目标
`~$` 临时文件、Thumbs.db、.lnk、.msg、.db 这些垃圾现在会进入处理链,造成大量无效失败、甚至搞崩进程池。要在**入队之前**就把它们拦掉。

## 先说明再动手
先找到入队路径(`kb_admin/state_store.py` 的 `enqueue_files()` 以及喂它的目录扫描逻辑),以及当前判定"支持的文件类型"的地方,说清现状、白名单从哪来、改哪几处,再动手。

## 具体改动
- 在入队前加过滤:
  - 跳过文件名以 `~$` 开头的(Office 临时/锁文件)。
  - 跳过 `Thumbs.db`、`*.lnk`、`*.msg`、`*.db` 等非文档文件。
  - 用"支持的扩展名白名单"放行(如 .pptx/.xlsx/.xlsm/.docx)——**白名单要从现有代码里真正支持的类型确认后再定,别硬编码,别漏掉需要的类型**。
- 被过滤的文件**不要入队**,或记为独立的 `skipped/ignored` 状态;**不要计入 dead/failed**,免得污染失败统计。
- 打印一条汇总日志:本次跳过 N 个(分别多少 `~$` 临时文件 / Thumbs.db / .lnk / ...)。

## 保持不变
- 真实业务文档照常入队;白名单必须覆盖所有需要的类型,**绝不能误删真文件**。
- 重试 / 崩溃计数 / 断点续跑 / 幂等 / 锁 / embedding 逻辑不变。

## 注意(不在本次范围)
有些扩展名正确、但内容损坏的老文件(个别 .xlsx 其实是坏压缩包)不归这层拦截——它们会照常入队、在解析阶段失败,由崩溃隔离兜底。门口过滤只管"一看名字就知道是垃圾"的那批。

## 验收标准
- `~$`、Thumbs.db、.lnk、.msg、.db 不再出现在 dead/failed;被跳过且有汇总日志。
- 真实文档不受影响,照常处理。
