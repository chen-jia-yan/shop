# 任务:修日志的 cp1252 编码报错,统一 UTF-8

## 目标
worker 写日志时遇到日文/非拉丁字符会报 cp1252 的 UnicodeEncodeError。要让日志统一走 UTF-8,并且遇到极端字符也只替换、绝不因为编码把任务写崩。

## 先说明再动手
先找到日志配置的地方(logging 配置 / FileHandler / basicConfig / 有没有共用的日志模块),用大白话说清现状、要改哪几处,再动手。

## 具体改动
- 所有写文件的日志 handler 设 `encoding="utf-8"`。
- 控制台输出(StreamHandler)也走 UTF-8;给 handler 加 `errors="replace"`(或 backslashreplace)兜底,保证遇到无法编码的字符只替换、不抛异常、不中断处理。
- 只改编码,不动日志格式、级别、轮转逻辑。

## 保持不变
日志内容/格式/级别/轮转规则;worker 主流程;其它一切。

## 验收标准
- 处理带日文路径/内容的文件时,日志正常写入,不再出现 UnicodeEncodeError。
- 旧日志仍可正常查看。
