### 2）启动服务
开发模式（热重载，文件改动自动重启）：
```bash
uv run uvicorn tap_ai.main:app --reload --port 9006
```

生产模式（关闭 reload）：
```bash
uv run uvicorn tap_ai.main:app --port 9006
```

默认端口 9006（`settings.port` / `TAP_AI_PORT`）。
- `uv run tap-ai`：读配置，不填则 9006
- `uvicorn ...`：必须自己加 `--port 9006`，否则 uvicorn 仍用 8000

备选启动方式（读取 `.env` 里的 `TAP_AI_PORT`，默认 9006）：
```bash
uv run tap-ai   # 等价于 tap_ai.main:main()
```

@asynccontextmanager
async def _lifespan(_app: object) -> AsyncIterator[None]:
    """应用启动清理孤儿附件；关闭时统一关闭登记过的运行时资源（连接池 / Redis 等）。

    - 启动: 清理"上传后从未绑定会话、已超时"的暂存附件（元数据 + Blob 字节），
      避免无会话上传积累杂质文件。
    - 关闭: 逆序关闭 ``lifecycle`` 里登记的资源。
    """
    from tap_ai.utils.workspace import reset_workspace_root

    app_state = cast(Any, _app).state if _app is not None else None
    if app_state is not None:
        file_service = getattr(app_state, "file_service", None)
        if file_service is not None:
            try:
                await file_service.cleanup_orphan_files()
            except Exception:  # 启动清理失败不阻断应用启动
                _tap_logger.warning("启动时清理孤儿附件失败", exc_info=True)

        await reset_workspace_root()

        # 预置 skill 同步（幂等、失败不阻断）。
        if app_state is not None:
            skill_sync_service = getattr(app_state, "skill_sync_service", None)
            if skill_sync_service is not None:
                try:
                    await skill_sync_service.sync()
                except Exception:  # strict 模式下失败会抛出，此处兜底记录
                    _tap_logger.warning("预置 skill 同步失败", exc_info=True)

        # 模型能力联调验证（失败不阻断启动；未验证能力在运行期按保守值处理）。
        if app_state is not None:
            capability_verify = getattr(app_state, "capability_verify", None)
            if capability_verify is not None:
                try:
                    await capability_verify()
                except Exception:
                    _tap_logger.warning("模型能力验证失败", exc_info=True)


        # 预热模型网关连接池，避免首个用户请求承担 TCP/TLS 建连开销。
        if app_state is not None:
            container = getattr(app_state, "container", None)
            registry = getattr(container, "model_registry", None)
            gateway = registry.get("model_gateway") if registry is not None else None
            warmup = getattr(gateway, "warmup", None)
            if warmup is not None:
                try:
                    await warmup()
                    _tap_logger.info("模型网关连接预热完成")
                except Exception:
                    _tap_logger.warning("模型网关连接预热失败", exc_info=True)
