# 提示词 2/4:调参预览沙盒(实时重切 + 新旧对比)

## 前置
在 1/4 完成之后做。

## 目标
在工作台里调 chunk 参数,**实时重切并预览**,和当前结果并排对比。仍然只预览、不入库。

## 参考
- ChunkViz https://github.com/gkamradt/ChunkViz — 抄"滑块调 size/overlap → 实时重切 → 结果即时更新"的交互。

## 唯一允许的核心改动(极小、向后兼容)
- 给 `_chunk_document()` 和 `_chunk_profile()` 加**可选 override 参数**(如 `profile_overrides=None`):
  - 不传 = 完全维持现有行为(生产零影响);
  - 传了 = 用临时 chunk_size/overlap 覆盖。
- **禁止 monkey-patch 改全局常量。** 除这一处外,不动切片核心。

## 功能
- 参数面板:chunk_size / overlap / 按内容类型(ppt/ocr/pdf/默认)分别调。
- **复用真的 `_chunk_document()`**(传 override)重切 —— 预览必须和生产切法一致。
- **解析只做一次**(读已落盘 artifact / 缓存 segments),切片随参数重跑(便宜),不重新 parse+OCR。
- 新旧参数并排对比(块数、每块 token、颜色质量变化)。

## 保持不变
预览不写正式索引、不入库;生产路径行为不变。

## 验收
- 拖参数能实时看到重切结果 + 新旧对比。
- override 默认不传时,生产切法完全不变。

## 验证方式
静态 + 单文件小测,不跑整个 worker。
