# 任务:embedding 超长(>8192 token)兜底,不改切分逻辑

## 背景
"保留 Excel 表格完整性"的切分会产生超过 8192 token 的大 chunk,embedding 报错。领导要求**不改切分、保留表格完整性**。所以只在 embedding 这一层加兜底。

## 先说明再动手
先找到调用 embedding(text-embedding-3-large)的地方(如 embed_chunk_batch / embedding provider),讲清现在怎么发送、准备在哪加护栏,再动手。

## 具体改动(只在 embedding 层)
1. 发 embedding 前估算每个 chunk 的 token 数,阈值设约 8000(留余量,别卡 8192)。
2. 超阈值的 chunk:切成多个 sub-window 分别 embedding,再 **mean-pool 合并成一个向量**;chunk 在存储/展示层**仍保持完整一块**。
3. **不改任何切分逻辑、不拆存储里的 chunk。**

## 保持不变
表格完整性、切分逻辑、chunk 在索引/展示里仍是完整一块;重试/续跑/幂等不变。

## 验收标准
- 之前报 8192 的文件能正常入库,不再报错。
- 大表格 chunk 在存储/检索结果里仍是完整一块。
- 普通大小的 chunk 完全不触发兜底、行为不变。

## 验证方式
静态 + 单文件小测(挑之前报错那个文件),不跑整个 worker。
