# 更新记录

## 1.2.0（2026-11-19）
- 项目自动识别：在哪个目录打开 Copilot 就用哪个项目。登记过的用登记设置；没登记的 git 仓库按 pyproject / uv.lock / tests 自动推断测试命令；不在仓库里当作普通助手，不走开发流程。
- 所有工具的 --project 都可以省略（默认当前目录）；新增 tools/kit_project.py（查看 / 登记 / 删除项目）。
- 桌面宠物简化：不用选项目（自动跟随 Copilot），单击直接告诉你“现在该做什么”，右键只保留 5 项，其余收进“更多工具”和“设置”；第一次打开有引导；新会话开始时会打招呼并显示项目。
- registry.json 支持 "pin": true，把常用按钮放到菜单第一层。

## 1.1.0（2026-11-19）
- 新增自动流程：技能 kit-autopilot + 总调度代理 kit-orchestrator。说需求后自动分析、出方案，回复“确认”后逐步执行、验证、评审；每次修复前先问你；git 提交仍由你执行。
- 个人规则和会话开头注入都写明“开发需求默认走自动流程”，不用每次手动调用。
- 适配公司 bat 只能开一个会话：执行和评审交给子代理（独立上下文），不再需要开新窗口；不支持委派时自动退回自己执行。
- 桌面挂件改成桌面宠物：Q 版小机器人 / 小猫，表情和动作跟着进度变化；需要你处理时跳起来提醒；守卫拦截时举盾牌；右键菜单来自 registry.json。
- 新增进度工具 kit_status.py；新增评估用例 a01（总调度必须等确认）；自测新增 3 项。

## 1.0.0（2026-11-18）
- 首个完整版本：11 个技能、6 个自定义代理、3 个钩子（会话注入、写前拦截、写后检查）、记忆系统、提示词体检与构建、静态检查与一键验证（带指纹缓存）、修改范围、提交助手、风格包 style-tap-backend（8 张卡片，待核对）、37 条评估用例、桌面挂件、脚手架、体检与自测。
