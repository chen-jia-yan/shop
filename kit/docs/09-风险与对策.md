# 09 风险与对策

## A. 工具包自身的风险
| # | 风险 | 后果 | 对策 | 你要做的 |
|---|---|---|---|---|
| A1 | **代码在编写环境里没有实际运行过** | 首次运行可能有小错误 | 所有模块都有自测；体检逐项给修复办法；守卫出错默认放行，不会锁死会话 | 安装后跑 kit_doctor、selftest、run_evals，把输出发给我 |
| A2 | 守卫有 bug 导致每次调用都被拒绝 | Copilot 什么都做不了 | 守卫捕获所有异常并放行（on_error=allow）；安装前自测 27 条用例 | 万一发生：`install.py --no-hooks` 立刻恢复 |
| A3 | 守卫误拦正常操作 | 打断工作 | 每条规则都有反向用例（git diff、2>&1、kg_browse.py、Markdown 里的文字） | 遇到误拦把拒绝原因发给我，加一条反向用例再修 |
| A4 | 守卫漏拦（换了写法绕过） | 规则失效 | 个人规则写明“被拒绝不得绕过”；验证阶段 checks.py 兜底（禁止标记、越界、编码） | 发现漏拦就加评估用例 |
| A5 | 1.0.75 不支持 exec 方式的钩子 | 旧版本没有硬拦截 | `--hook-style powershell`；规则 + 验证兜底 | 两个版本都做一次“读 .env”测试 |
| A6 | 钩子超时被当作放行 | 拦截失效 | 守卫只做文本判断，不运行外部命令 | — |
| A7 | 会话注入的上下文过长或过期 | 占额度、误导模型 | 上限 1800 字；只注入核对通过的记忆 | 定期“核对是否过期” |
| A8 | 风格卡片和代码不一致 | 照着错误的样例写 | 卡片标“待核对”，以代码为准；核对日期超 120 天 kit_lint 提醒 | 第一次用前用 /kit-extract-pattern 核对 8 张卡 |
| A9 | 记忆里混进敏感信息 | 泄露 | 保存时识别口令、密钥、连接串并拒绝 | 分享前翻一遍 memory 目录 |
| A10 | 桌面宠物的透明背景在个别显示设置下显示成粉色方块 | 不好看 | 透明色只在 Windows 生效，用的是几乎不会出现的颜色 | 出现时截图发我；宠物的弹窗（说需求、结果）是普通窗口，输入中文不受影响 |
| A13 | 自动流程没有被触发（模型没按规则走） | 没出方案就开始改 | 三层保障：个人规则、会话开头注入、直接选 kit-orchestrator；守卫的修改范围仍然有效 | 说一句“按 /kit-autopilot 流程来”，或 /agent 选总调度 |
| A14 | 软确认：模型理论上可能没等你确认就动手 | 提前改了文件 | 规则写明“确认前不改文件”，并有评估用例 a01 专门检查；所有改动都还没提交，git diff 能看到 | 发现就说“停”，用 git diff 查看；需要更严格时可以改成硬门槛（告诉我） |
| A15 | 1.0.75 不支持委派子代理或子代理指定模型 | 上下文变长 | 总调度会退回自己执行，规则不变；用 /compact | 按文档 01 的方法确认一次 |
| A11 | 工具包目录被挪动 | 技能里的路径、钩子失效 | 体检会发现路径不一致 | 挪动后重新运行 install.py |
| A12 | `isolated_import_modules` 里的模块导入时需要配置 | 慢检查误报 | 只在 `--full` 时运行 | 误报就从配置里去掉该模块 |

## B. 你项目里的业务风险（工具包已经针对性设防）
| 风险 | 防线 |
|---|---|
| 写入 jp-poc 只读索引 | 项目注意事项注入每个会话；风格卡片 03/05 要求写前检查禁止写入的索引；评审清单“权限与数据范围” |
| 删除或修改共享 Neo4j 里 hk 的数据 | 注意事项注入；守卫拦截命令里出现 `DETACH DELETE`；评审清单要求带范围条件 |
| 读取 .env / .env.example（后者含真实口令） | 守卫硬拦截读取和打印；**建议尽快轮换 .env.example 里的口令** |
| 改同事的问答插件 | 守卫 protected-area 拦截（kg_browse.py 除外）；scope_diff 检查 |
| git add . 带上脏的 fwd-tap-common 子模块 | 守卫拦截 git 写操作；提交助手点名添加并识别子模块 |
| 直接在 develop/master 上改 | 提交助手警告；注意事项注入 |
| 测试连真实服务 | 个人规则 + env_in_tests 检查 + 测试卡片 |
| 选了“Yes, and don't ask again” | 规则无法替你挡住这个按钮。**永远不要选它**；守卫不受这个选项影响，仍会拦截 |

## C. 使用习惯上的风险
| 风险 | 对策 |
|---|---|
| 一次给太多任务 | 需求体检会提示拆分；一次一步 |
| 只看报告不看证据 | 评审代理要求原始输出和文件:行号；核对表逐条写证据 |
| 额度用得快 | 见 06：分阶段开会话、/compact、本地工具优先 |
