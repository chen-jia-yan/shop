继续用 LOAD CSV（不要改成一条切片一条语句的方案，那样会撑爆 Browser）。问题是 CSV 里正文的引号没处理干净，按下面把正文里的双引号去掉，让 CSV 不可能再出引号解析错。
红线：只读 data\kb_admin\jsonl\；不碰 kg.db 写、Azure、state.db、现有 JSON；不动已导入的节点/边/关系；只给 Chunk 节点补 content。

1. 用 Python 重新生成 data\kg\neo4j_export\chunk_content.csv：
   import csv, json, glob, re
   out='data/kg/neo4j_export/chunk_content.csv'; seen=set(); rows=[]
   for path in glob.glob('data/kb_admin/jsonl/file-*.jsonl'):
       with open(path, encoding='utf-8') as f:
           for line in f:
               line=line.strip()
               if not line: continue
               r=json.loads(line); cid=r.get('chunk_id')
               if not cid or cid in seen: continue
               seen.add(cid)
               c=(r.get('content') or '').replace('\x00','')
               c=re.sub(r'[\x00-\x1f]+',' ',c)   # 换行/制表/控制字符→空格
               c=c.replace('"','”')               # 关键：去掉会破坏CSV的双引号
               c=c[:1500]
               rows.append((cid,c))
   with open(out,'w',encoding='utf-8',newline='') as f:   # 注意不要用 utf-8-sig，避免 BOM
       w=csv.writer(f, quoting=csv.QUOTE_ALL)
       w.writerow(['chunk_id','content']); w.writerows(rows)
   把新文件复制进 Neo4j 的 import 文件夹，覆盖旧的。

2. 在 Neo4j Browser 里跑这一条（content 的 SET 是覆盖式，幂等，之前跑残了也没关系）：
   LOAD CSV WITH HEADERS FROM 'file:///chunk_content.csv' AS row
   MATCH (c:Node {node_id: row.chunk_id}) SET c.content = row.content;
   如果嫌慢或报内存，改用分批版（Browser 里必须加开头的 :auto）：
   :auto LOAD CSV WITH HEADERS FROM 'file:///chunk_content.csv' AS row
   CALL { WITH row MATCH (c:Node {node_id: row.chunk_id}) SET c.content = row.content } IN TRANSACTIONS OF 2000 ROWS;

3. 报告：成功匹配到 content 的 Chunk 节点数、未匹配数、有无报错。
