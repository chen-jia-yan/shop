步骤 1 · 导出 CSV 到 data\kg\neo4j_export\（UTF-8，正确转义）：
- nodes.csv：全部节点
  SELECT node_id, type, label,
    (SELECT GROUP_CONCAT(doc_id,'|') FROM kg_node_sources s WHERE s.node_id=kg_nodes.node_id) AS source_docs,
    json_extract(metadata_json,'$.source_file') AS source_file,
    json_extract(metadata_json,'$.page_or_sheet') AS page_or_sheet
  FROM kg_nodes;
- edges.csv：全部边
  SELECT e.source_id, e.target_id, e.type,
    (SELECT GROUP_CONCAT(doc_id,'|') FROM kg_edge_sources s WHERE s.edge_id=e.edge_id) AS source_docs,
    e.provenance_inferred
  FROM kg_edges e;
- nodes_files.csv：实体→真实文件名
  SELECT n.node_id,
    (SELECT GROUP_CONCAT(DISTINCT dm.source_file)
     FROM kg_node_sources s
     JOIN (SELECT DISTINCT ns.doc_id AS doc_id, json_extract(cn.metadata_json,'$.source_file') AS source_file
           FROM kg_node_sources ns JOIN kg_nodes cn ON cn.node_id=ns.node_id WHERE cn.type='Chunk') dm
       ON dm.doc_id=s.doc_id
     WHERE s.node_id=n.node_id) AS source_files
  FROM kg_nodes n WHERE n.type<>'Chunk';
- chunk_content.csv：切片正文（用 Python 的 csv 模块写，QUOTE_ALL，UTF-8）。遍历 data\kb_admin\jsonl\file-*.jsonl 每一行，输出 chunk_id, content, source_file, page_or_sheet。
把需要的 CSV 复制进 Neo4j 的 import 文件夹。

步骤 2 · 生成 import_all.cypher（分段，便于我核对）：
a. 清空试点库（确认是 localhost 试点库后）：MATCH (n) DETACH DELETE n;
b. 唯一约束：CREATE CONSTRAINT node_id_unique IF NOT EXISTS FOR (n:Node) REQUIRE n.node_id IS UNIQUE;
c. 建全部节点：LOAD CSV WITH HEADERS FROM 'file:///nodes.csv' AS row
   CREATE (n:Node {node_id:row.node_id, type:row.type, label:row.label, source_docs:row.source_docs,
                   source_file:row.source_file, page_or_sheet:row.page_or_sheet});
   （行数多，用 CALL { ... } IN TRANSACTIONS OF 2000 ROWS 分批）
d. 加类型标签（按 type 给节点加对应 label，自动按 kg_nodes 里出现的 distinct type 生成，含 Chunk→:Chunk）：
   例如 MATCH (n:Node {type:'System'}) SET n:System; … 每种类型一条。
e. 加文档名：LOAD CSV WITH HEADERS FROM 'file:///nodes_files.csv' AS row
   MATCH (n:Node {node_id:row.node_id}) SET n.source_files=row.source_files;
f. 加切片正文：LOAD CSV WITH HEADERS FROM 'file:///chunk_content.csv' AS row
   MATCH (c:Node {node_id:row.chunk_id}) SET c.content=row.content;
   （分批 IN TRANSACTIONS；完成后报告：有多少 Chunk 节点成功匹配到 content、多少没匹配上——没匹配上说明 chunk_id 对不齐，要告诉我。）
g. 建关系【真实类型】：先从 edges.csv 读出所有 distinct type，为【每一种】类型生成一段：
   LOAD CSV WITH HEADERS FROM 'file:///edges.csv' AS row
   WITH row WHERE row.type = '<该类型>'
   MATCH (a:Node {node_id:row.source_id}),(b:Node {node_id:row.target_id})
   CREATE (a)-[:`<该类型>` {source_docs:row.source_docs, inferred:row.provenance_inferred}]->(b);
   非 ASCII 的类型名（中文/日文）必须用反引号包。mentioned_in 等大批量用 CALL {} IN TRANSACTIONS 分批。
