解法 A（先试这个）：
1. 用下面的 Python 重新生成 data\kg\neo4j_export\chunk_content.csv（务必用 csv 模块，别手拼字符串）：
   import csv, json, glob, re, os
   out = 'data/kg/neo4j_export/chunk_content.csv'
   seen = set(); rows = []
   for path in glob.glob('data/kb_admin/jsonl/file-*.jsonl'):
       with open(path, encoding='utf-8') as f:
           for line in f:
               line = line.strip()
               if not line: continue
               r = json.loads(line)
               cid = r.get('chunk_id')
               if not cid or cid in seen: continue
               seen.add(cid)
               c = (r.get('content') or '').replace('\x00','')
               c = re.sub(r'[\x00-\x1f]+', ' ', c)   # 换行/制表/控制字符全压成空格
               c = c[:1500]
               md = r.get('metadata') or {}
               rows.append((cid, c, md.get('source_file',''), md.get('page_or_sheet','')))
   with open(out, 'w', encoding='utf-8', newline='') as f:
       w = csv.writer(f, quoting=csv.QUOTE_ALL)   # 默认 doublequote=True，内部 " 会变 ""，匹配 Neo4j
       w.writerow(['chunk_id','content','source_file','page_or_sheet'])
       w.writerows(rows)
   把新 chunk_content.csv 复制进 Neo4j 的 import 文件夹（覆盖旧的）。

2. 在 Neo4j 里重跑（分批，覆盖式 SET，幂等）：
   LOAD CSV WITH HEADERS FROM 'file:///chunk_content.csv' AS row
   CALL { WITH row MATCH (c:Node {node_id: row.chunk_id}) SET c.content = row.content } IN TRANSACTIONS OF 2000 ROWS;

3. 报告：成功匹配到 content 的 Chunk 节点数、未匹配数、以及这次有没有报错。

解法 B（仅当解法 A 仍报转义/格式错时用，彻底不走 CSV）：
用 Python 读 jsonl，生成 data\kg\neo4j_export\set_content.cypher，每个切片一条语句，内容做 Cypher 字面量转义：
   safe = c.replace('\\','\\\\').replace("'","\\'")
   语句形如：MATCH (c:Node {node_id:'<cid>'}) SET c.content='<safe>';
   （cid 一般是十六进制，无需转义；content 用上面 safe。每 2000 条之间无需事务包裹，cypher-shell 顺序执行即可。）
然后 cypher-shell -u neo4j（我手动输密码）执行 set_content.cypher。

两种都不要碰节点、边、关系类型，只给 Chunk 节点补 content。
